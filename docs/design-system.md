## 1. 定位与目标

baize 是做企业 AI Native 转型的咨询、培训和 FDE 服务公司（GitHub issue #3）。网站要完成两件事：

1. 让访客预约一次咨询。
2. 让访客记住 baize 能帮企业落地 AI Native 转型。

网站同时是内容站。图文和视频教程承担 SEO 获客，SEM 落地页承接付费流量。设计必须服务这两条流量路径，不能只做品牌展示。

白泽青的取名来自神兽白泽：深墨绿压底，翡翠绿发光，东方感和科技感都有。

## 3. 色彩

### 3.1 色彩 token

| Token | 值 | 角色 |
| --- | --- | --- |
| `--accent` | `#14E0A0` | 翡翠绿。按钮、激活态、光点、大色块 |
| `--on-accent` | `#04221A` | 写在翡翠绿上的文字和图标 |
| `--accent-ink` | `#06805A` | 白底上的绿色小字、链接、标签文字 |
| `--ink` | `#0A1F1C` | 正文与标题 |
| `--ink-2` | `#3C4B48` | 次级正文、导航 |
| `--muted` | `#5A6B67` | 元信息、说明 |
| `--dark` | `#062A25` | 深墨绿。首屏、服务区、视频、页脚 |
| `--dark-card` | `#0D3A33` | 深色区里的卡片与徽章 |
| `--on-dark-muted` | `#B9D3CD` / `#8FB5AC` | 深色区里的副文字 / 元信息 |
| `--soft` | `#EAF5F1` | 浅绿区块底色（入门路径、FAQ、继续读） |
| `--chip` | `#D6F7EC` | 浅绿标签底 |
| `--line` | `#E4E7EC` | 分隔线、卡片描边 |
| `--bg` | `#FFFFFF` | 页面底色 |

内容卡片的占位底色轮换使用 `#C9F5E6 #D9ECFF #E9E1FF #FFE3D6 #D2F0F5 #E6F7C9`。正式上线由配图替代。

### 3.2 用色规则

- 翡翠绿在白底上只做「面」和「点」：按钮、色块、圆点。白底上的绿色文字一律用 `--accent-ink`，`#14E0A0` 在白底上对比度不够。
- 翡翠绿上的文字用 `--on-accent`，不用白色。
- `--dark` 只用于需要「压住」的区块：首屏（专题页）、服务区、视频位、文中服务推广、页脚。一屏内深色区块不超过一个。
- 页面不用暖色中性色（米白、暖灰）。v1/v2 的纸质感已废弃。
- 不新增第二个强调色。错误态用系统红，只出现在表单校验里。

## 5. 形状、间距、动效

- 圆角：按钮和标签为胶囊 `999px`；卡片 `20px`；大卡片和推广块 `24px`；预约大色块 `28px`；小色块 `12–16px`。
- 描边：`1px solid var(--line)`。不用粗边框。
- 阴影：静止时无阴影。卡片 hover 上浮 3px，阴影 `0 12px 32px rgba(10,31,28,.08)`，过渡 200ms。
- 版心：`max-width: 1240px`，左右内边距 32px。文章正文栏 860px，FAQ 880px。
- 区块上下间距：96px（首页）/ 80px（内页）。
- 点击目标不小于 44px 高。
- 动效遵守 `prefers-reduced-motion`。不做循环装饰动画。

## 7. 页面模板

信息结构：专题分组 → 专题 → 文章。URL、面包屑、站点地图、`BreadcrumbList` 都从这个结构派生。

| 页面 | 作用 | 区块顺序 |
| --- | --- | --- |
| 首页 | 品牌 + 分流 | Header → 首屏（徽章 / H1 / 副标题 / 双按钮 / 数据卡）→ 服务（深色）→ 免费教程（Tab 筛选）→ 专题标签（浅绿）→ 预约大色块 → 页脚站点地图 |
| 专题页 | SEO 聚合页，一个专题一个关键词 | 深色首屏（面包屑 / H1 / 数量）→ 入门路径 → 全部文章 + 侧栏服务推广与相关专题 → FAQ → 页脚 |
| 文章页 | SEO 落地 + 引向服务 | 面包屑 / 标签 / H1 / 摘要 / 作者元信息 → 封面 → 目录 + 正文（视频位、要点框、文中推广、FAQ）→ 继续读 → 页脚 |
| SEM 落地页 | 付费流量转化 | 极简 Header（logo + 电话，无导航）→ 深色首屏（关键词 H1 + 卖点 + 右侧短表单）→ 模块/流程 → 三篇教程 → FAQ → 极简页脚 |

SEM 落地页按投放关键词切换 H1、副标题、卖点、模块和按钮文案。当前三套：企业 AI 培训、FDE 驻场开发、AI 转型咨询。H1 直接写搜索词。

## 9. 配图

笔记与教程配图仍用 `guizang-material-illustration` 技能（3D 物料 / 瑞士编辑风），强调色从站点橙改为白泽青。2026-10-22 试色结论：

| 用途 | 方案 | 规格 |
| --- | --- | --- |
| 封面 | B 深底 | 深墨绿背景 `#062A25`，哑光深绿与浅灰物体，翡翠绿 `#14E0A0` 作发光强调，无文字 |
| 正文配图 | A 浅底 | 冷白背景 `#F4F6F5`，浅灰物体黑色细描边，翡翠绿只做点和面，`#06805A` 做描边细节；中文标签放白色标注板 |

理由：深色封面在微信、飞书的白色信息流里最醒目，也和网站深色区块一致；正文是白底，浅底配图读起来轻。翡翠绿在浅底上不能做细线和字。

试色样张：`jade-A-cover.png`、`jade-A-fig.png`、`jade-B-cover.png`、`jade-B-fig.png`（会话 scratchpad，未入库）。已有的橙色配图是否重做、按什么顺序重做，待定。

## 10. 响应式与可访问性

- 断点：Mobile 0–767px，Tablet 768–1023px，Desktop ≥1024px。布局用 flex-wrap / auto-fit 网格，窄屏自然变单列。
- 移动端：导航折叠；首屏 H1 不超过 3 行；服务卡、表单单列。
- SEM 落地页在移动端要把表单排到卖点之前，或加底部悬浮「预约」按钮（待做）。
- 对比度满足 WCAG AA；按钮和链接有 focus 状态；表单字段有 label；状态不只靠颜色表达；图片有 alt。
