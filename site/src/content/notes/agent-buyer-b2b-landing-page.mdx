Agent 买家替采购方读页面、核规格、比报价、提交询价，最后拍板的大多还是人。所以落地页要同时写给两类读者：给 Agent 买家看的，是能直接抽取的事实，比如规格、价格口径、交付条件、资质、联系方式；给人看的，是信任和取舍。只有说服话术、没有可核对事实的页面，Agent 买家可能直接跳过。

## 读取和理解页面：平铺业务定义与适用范围

Agent 买家进入落地页，首先抓取文本并提炼核心业务事实。

Paul Graham 2026 年 10 月 8 日在 X 上写到：人们会想让 Agent 替自己买东西，这会是 Agent 的主要用途之一。Paul Graham 2026 年 10 月 12 日在 X 上写到：他在答疑时建议一位偏技术的创始人找一个更外向的联合创始人做销售，对方说不需要，因为他的大部分销售对象会是 Agent；Paul Graham 说对方可能是对的。

我们的判断是：买方派出的 Agent 初筛时只抓取产品定义、服务对象和核心能力。如果页面只有修辞而缺乏实体陈述，Agent 买家无法生成采购摘要，会直接跳过。

它在页面上找什么：明确的产品定义与适用场景。比如采购协同工具还是财务系统，支持私有部署还是 SaaS，面向小微团队还是大型组织。

页面怎么写它才找得到：在首屏和小标题下用短句陈述事实。答案引擎如何从小标题首段抽句，见 <NoteLink slug="answer-first-for-answer-engines">内容先给答案，答案引擎才抽得走</NoteLink>。至于 llms.txt 的写法，本文不展开；把产品属性与适用边界平铺在文本中，机器就能稳定解析。

这一步什么时候交回给人：提取基础信息后，若业务范围与采购需求不完全匹配，或者技术路线分歧较大，由采购人员人工复核初筛报告，决定是否入围。

## 核对规格与资质：参数给清实数，资质明示编号

初筛之后，Agent 买家会逐项核对技术规格与合规资质。我们的判断是：买方会把指标拆成固定字段逐项比，页面没写的指标，很可能被记为缺项。

它在页面上找什么：系统硬性指标与合规证明。比如并发吞吐量、单点登录协议、数据存储地域、备份周期，以及安全合规认证编号。

页面怎么写它才找得到：我们建议把规格整理成表格或清单，证照写明全称与编号。写清具体数值、协议版本与认证等级，比如写明支持哪种单点登录协议及其版本，持有哪一级等保认证及证书编号。抓取到具体参数后，机器可直接填入对比表。

这一步什么时候交回给人：若页面缺少关键合规项，或者要求出具定制保密承诺，Agent 在报告中标注资质存疑，由安全与法务人员人工审查。

## 比较价格与条款：公开计费口径，写明起售门槛

Agent 买家比较报价，依赖公开透明的计费口径与阶梯规则。我们的判断是：价格藏在咨询表单后面，Agent 买家批量测算成本时拿不到基准，这家供应商在初筛里容易排到后面。

它在页面上找什么：计费口径、起售门槛与附加成本。比如按席位、按调用量还是按年收费；最低起售席位；免费试用期天数；扩容资源单价；以及退款与续约规则。

页面怎么写它才找得到：我们建议在定价区域写明版本权益与计费单位，不强制访客填表才看价格。横向对比竞品时，具体表格结构见 <NoteLink slug="b2b-comparison-page-ai-citation">B2B 对比页怎么写，AI 才肯引用</NoteLink>。写清适用范围与限制条件，Agent 买家就能折算年化支出，生成标准化报价清单。

这一步什么时候交回给人：采购规模达到大额年框折扣线、申请特殊账期，或者涉及定制协议时，Agent 整理完各家公开价与条款差异后，由人工商务代表介入谈判。

## 提交询价或申请：保留表单字段语义，拍板留给人

完成初筛与比价后，Agent 买家会代表企业发起试用或提交询价需求。我们的判断是：表单字段含义不清，Agent 买家就难以准确填写和提交。

它在页面上找什么：易于机器识别的表单入口。比如企业邮箱输入框、公司名称、需求描述字段、试用申请按钮，以及开发者接口申请入口。

页面怎么写它才找得到：我们建议表单使用规范的 HTML 标签，标注明确的 label 与 name 属性，并在表单旁提供技术联系邮箱。是否允许自动提交、怎么防垃圾询价，由卖方自己权衡。至于 Agent 在企业内部使用谁的身份和凭证权限，本文不展开。

这一步什么时候交回给人：提交申请是 Agent 买家替企业跑腿的最后一步。后续的试用评估、合同签署与付款审批，由采购负责人与业务主管拍板。

## Agent 买家：常见问题

### Agent 买家进入采购流程后，落地页上针对人类买家的客户案例还要保留吗？

我们建议保留客户案例与信任背书。Agent 买家负责前期的信息搜集与初筛，整理候选短名单；最终拍板采购决策、承担采购风险的大多是企业管理者。同行案例与交付信誉，是人类决策者权衡风险的核心参考。落地页要做到两类内容并存：给机器提供可抽取的事实参数，给人类决策者提供建立信任的真实证据。

### 为什么不能把所有价格和规格参数都藏在留资表单后面？

我们的判断是：隐藏价格和关键参数会增加初筛摩擦成本。企业指派 Agent 买家批量调研时，无法直接提取参数的供应商会被标记为信息不透明，或者排在候选清单后列。公开基础规格、计费模式与起售门槛，能让产品在机器筛查阶段顺利入围；定制需求再引导商务沟通。

### 企业改造既有的 B2B 落地页时，应当优先补充哪几类机器可抽取的关键信息？

我们建议分三步补充关键信息：第一步，在页面首屏与核心段落，平铺无歧义的产品定义、适用行业与部署形式；第二步，将系统规格与合规资质做成结构化表格或清单，写明证书名称与编号；第三步，公开透明的基础定价口径与起售门槛。这样调整后，页面既能让 Agent 买家高效抓取比价，又能让人类采购者快速看懂产品价值。
