## 诉讼保留和自动清理谁优先

企业平时有邮件自动清理规则，配好邮件保留策略定期清理旧邮件，也有 Agent 帮员工整理、归档、删除邮件。一旦企业遇到案件或调查，法务发出诉讼保留通知，相关人员的邮件就要保留下来不删，自动清理规则和 Agent 的删除动作都要服从诉讼保留。

根据一款主流办公邮件平台的官方合规文档，邮件处在电子取证保留或诉讼保留下时，在保留策略和保留标签的判断之前就会被保留；同一封邮件要因另一条保留策略或保留标签保留、或处在电子取证保留下时，永久删除会被暂停。在这样处理的邮件系统里，保留排在自动清理前面。法务在准备案件材料、核对判例和内部邮件记录时，怎么核实 AI 给出的判例，见 <NoteLink slug="legal-research-ai-case-check">法律检索 AI 给的判例，引用前怎么核？</NoteLink>。

## 法务通知后 IT 和 Agent 各做什么

法务发出保留通知后，通知单上列明涉及的人员邮箱与案件范围，先由 IT 在邮件系统里对相关人员的邮箱加上诉讼保留或电子取证保留，把相关邮件留住。同时，企业把帮员工整理、归档、删除邮件的 Agent 权限收紧，Agent 对这些处在保留下的邮箱暂停删除和移动类动作，改成只读模式，只做查阅与检索，不再改动邮件位置或删信。

在保留期间，就算员工自己在邮箱里把邮件移进废纸篓或点了删除，邮件系统也要能把删掉的邮件找回来。Agent 平时的每一次删除动作都要留有运行日志；在诉讼保留期间，一旦出现针对这些受保护邮箱的删除尝试，不管来自员工手动操作还是工具触发，日志都要记录下来并报给法务处理。

## 邮件保留策略要不要改

不少团队会问，启动诉讼保留之后，原来配好的日常邮件保留策略和自动清理规则要不要停掉或修改。一般不用改，因为保留优先于日常清理：在上面提到的那款主流办公邮件平台里，邮件处在电子取证保留或诉讼保留下时，在保留策略和保留标签判断之前就会被保留，永久删除也会被暂停。

不过，不同邮件系统的处理方式不一样，有的系统未必按这个顺序执行。企业在上线自动清理规则和邮件 Agent 之前，要先在自己实际使用的邮件系统里确认是不是这样处理，拿测试邮箱加上保留后再跑一遍自动清理和 Agent 删除，测清楚邮件确实不会被删掉、员工自己删了也能找回。业务与法务团队日常留存合规台账的做法，见 <NoteLink slug="aigc-ad-assets-vs-legal-ledger">AIGC 投放素材出得再快，广告法务台账缺什么</NoteLink>。

## 保留怎么解除与留什么记录

诉讼保留什么时候解除，不能由业务人员或 IT 自己决定，要由法务发出书面通知，IT 再去邮件系统里执行解除，并记录解除的时间。按照上述主流办公邮件平台的官方合规文档，删除内容、解除保留之前，要先查清这个位置上所有的保留来源，因为任何一个保留来源都足以让内容继续留着。

也就是说，如果某个邮箱同时涉及别的案件保留，或者还命中了另一条保留策略、保留标签，单解除当前这起案件的诉讼保留，邮件还是会因为其他保留来源而继续留存。合规文档还写明，解除诉讼保留后，系统会自动加上一段延迟保留。

## 诉讼保留：常见问题

### 诉讼保留期间员工删了邮件怎么办？

法务发出保留通知并由 IT 对相关人员邮箱加上保留后，员工就算自己动手删了邮件，也要能从系统里找回来。按照主流办公邮件平台的合规文档，邮件处在电子取证保留或诉讼保留下时，永久删除会被暂停；同时，保留期间如果有删除尝试，记录要报给法务。

### 诉讼保留什么时候能解除？

由法务发出书面通知后，IT 再去系统里执行解除，并记录时间。解除保留之前，要先查清这个位置上所有的保留来源，任何一个保留来源都足以让内容留着；另外，根据主流办公邮件平台的合规文档，解除诉讼保留后，系统会自动加上一段延迟保留。

### 有了诉讼保留，邮件保留策略还要改吗？

一般不用改，保留优先于日常的邮件保留策略和自动清理规则。不过不同邮件系统的处理方式不一样，企业要在自己使用的邮件系统里提前测清楚，确认加上诉讼保留后自动清理和 Agent 删除确实不会把邮件永久删掉。
