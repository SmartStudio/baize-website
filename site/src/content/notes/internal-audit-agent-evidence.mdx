企业把报销初审、付款申请、主数据修改交给 Agent 处理时，AI 审计留痕要做到内审抽一张单，就能看清这张单从头到尾谁做了什么：Agent 读了哪些数据、调了哪个工具、做了什么判断、依据哪条规则、哪一步交给了人、人批了什么。Agent 操作日志要按单号可查，Agent 自己不能改也不能删；规则、提示词和模型版本变更也要留存版本记录，确保事后能还原当时的判断依据。

## 一张单要留哪些痕

当内审人员从财务或业务系统里抽出一张报销单、一笔付款申请或者一条主数据修改单时，光看到最后写着已通过或已驳回是不够的。一张单据从提交到办结，中间经过 Agent 处理的每一个环节都要挂在单据的审计轨迹上，让查单的人顺着时间线就能复盘全过程。

具体到单据层面，要留住两段链条：前半段是机器怎么干的，包括 Agent 接单后去哪些表里读了什么字段、比对了哪几张发票或合同附件、依据企业哪一条制度条款得出了初审通过或拦截的结论；后半段是怎么跟人交接的，写明 Agent 在哪一步触发了停机或转交条件、把单子推给了哪位审批人、审批人看到了什么提示信息、最后签批了同意还是退回。Agent 跑到哪一步该停下来交给人、决策记录怎么留，见 <NoteLink slug="agent-stop-conditions-decision-log">Agent 安全护栏：无人值守跑到什么程度该停</NoteLink>。

## Agent 操作日志记什么

为了支撑单据层面的复盘，底层的 Agent 操作日志要把每一次执行细节记全。只记一句某年某月某日处理完某单不够用，要把单次任务拆成结构化的字段逐条落库：

- **时间与任务编号**：记录动作发生的具体时间戳、全局唯一的任务编号，以及关联的业务单据号，保证能按单号直接反查出整串操作。
- **账号与权限范围**：记下 Agent 执行该任务时使用的是哪个服务账号、当时挂载了哪些数据读取权限和接口调用权限。
- **输入与输出内容**：保存喂给 Agent 的原始单据内容、上下文参数，以及 Agent 最终输出的判断结论、结构化字段或修改建议。
- **工具调用与交接记录**：记清 Agent 期间调用了哪些外部工具或内部接口、传了什么参数、返回了什么结果，最后在哪个节点交接给了哪位员工处理。工具调用时哪些能直接放行、哪些要拦下来由人批，见 <NoteLink slug="agent-tool-call-auto-approval-rules">Agent 工具调用自动审批：哪些放行、哪些拦下</NoteLink>。

除了运行时的操作日志，Agent 依赖的业务规则、系统提示词和模型版本，每次修改上线都要打上版本号归档。若只留单据日志却没留当时的规则和提示词版本，隔几个月内审回头来查时，就对不上 Agent 当天按哪套口径算出的结论。

## 谁能看与谁不能改

日志记下来之后，还要管好读写权限。如果 Agent 自己既有写日志的权限，又有改日志或删日志的权限，那这套记录在内审眼里就没有证明力。系统可以配置成日志采集模块单向写入独立的审计存储库，Agent 自己的运行账号对审计库没有任何修改和删除权限，业务系统的日常管理员也不能随便进去改记录。

查询权限则交给内审、合规和安全团队。审计存储库要支持按业务单据号、任务编号、操作时间段或服务账号直接检索，内审抽到哪张报销单或付款单，输入单号就能把对应的 Agent 操作日志、规则版本号和人工审批记录一并调出来导出。至于日志保留多久，企业按自身内控制度和适用法规来定，保存期限不短于法规要求；例如《中华人民共和国网络安全法》（二〇二五年修正）第二十三条规定，网络运营者应当按照网络安全等级保护制度的要求，履行安全保护义务，其中第三项是采取监测、记录网络运行状态、网络安全事件的技术措施，并按照规定留存相关的网络日志不少于六个月。

## 内审抽单怎么查

内审人员拿到抽样单据和对应的日志包后，核查重点集中在三件事上。第一件是查结果对不对：把原始报销发票、付款合同或主数据变更申请拿出来，对照当时生效的那一版业务规则，看 Agent 给出的初审结论或字段修改结果跟制度要求是否吻合，有没有算错金额或漏看附件。

第二件是查过程有没有越权：翻看 Agent 操作日志里的账号权限和工具调用记录，核实它在办这张单子时，有没有去读不该读的敏感表，有没有跳过预设的校验接口直接去改核心库。第三件是查该由人批的环节有没有人批：对照企业的审批矩阵，看超出设定的阈值或命中特殊规则的单子，Agent 有没有停下来转交人工，人工签批的记录是不是真实完整、有没有未批先放行的情况。

## AI 审计留痕：常见问题

### AI 审计留痕和普通系统日志有什么区别？

普通系统日志主要记接口通不通、报没报错、谁在什么时候点了一下按钮；AI 审计留痕除了记这些基础操作，还要多记两类核心证据：一是 Agent 做出某项判断时依据了哪条规则、哪版提示词和哪些输入数据，二是机器在哪个节点把任务交接给了人工、人工看到了什么并批了什么。

### Agent 规则改了，以前的单还能查吗？

能查，前提是对业务规则、提示词和模型版本做了版本管理。每次改动规则都生成新版本号，并在单据日志里记下当时调用的版本；内审抽查旧单时，调出单据日志绑定的历史规则版本，即可按当时的口径复核对错。

### Agent 操作日志要保存多久？

保存期限由企业按内部审计制度和适用法规确定，不短于法规要求。《中华人民共和国网络安全法》（二〇二五年修正）第二十三条对网络日志的规定是按照规定留存相关的网络日志不少于六个月；企业还可结合财务凭证、合同档案等保管要求，为绑定业务单据的 Agent 操作日志设定更长的留存期。
