用印审批 Agent 可以接手申请单要素核对、待盖文件与审批定稿比对、按印章类型分发审批人以及进度催办和留痕；盖章前有几步留给人：审批人查看文件后决定同意或驳回，公章和对外承诺类文件由法务审核，电子签章的签署意愿认证与最终落章由有印章权限的人本人完成，印章权限不授予 Agent 账号。

## 申请进来先核什么

没有印章权限的经办人在系统里发起签署任务、选定要盖的印章并提交用印申请后，用印审批 Agent 先做前置核验。它逐项检查申请单要素齐不齐，包括待盖文件附件、用印用途说明、申请的印章类型、用印份数以及签约对方主体名称；缺项或附件打不开的申请单直接退回经办人补齐，不往审批人工作台推送。

要素核齐后，用印审批 Agent 把经办人本次上传的待盖章文件，同此前合同评审或业务审批通过的定稿版本做全文比对。如果发现待盖文件在定稿之后又改了条款文字、金额、日期或附件页，流程立即停下并退回重新走审批。哪些前置校验动作可以配置成放行、哪些动作要拦下转人，划分原则见 <NoteLink slug="agent-tool-call-auto-approval-rules">Agent 工具调用自动审批：哪些放行、哪些拦下</NoteLink>。

## 审批按什么规则分给谁

企业的电子签章系统可以按印章类型和申请人设置条件分支，也可以给不同印章分别建审批模板，人事专用章、合同专用章、公章各走各的审批人。

用印审批 Agent 读取申请单上的印章类型和申请人信息后，按预设模板把任务路由给对应的审批节点。例如，人事专用章路由给人力资源负责人审批，日常业务合同专用章路由给对应业务部门负责人和法务审批，动用公司公章或签署对外承诺函、担保函这类高风险文件，则固定流转给法务及公司管理层逐级把关。

收到通知的审批人在系统里打开待盖文件，核对业务背景和比稿报告后，由本人点击同意或驳回。用印审批 Agent 只负责把文件、比对结果和流转提醒送到审批人手头，不替任何一级审批人点通过。

## 盖章那一步为什么留给人

审批节点全部通过后，进入实际盖章环节，这一步不能交由 Agent 代劳。《电子签名法》第十四条规定，可靠的电子签名与手写签名或者盖章具有同等的法律效力；第十三条列的可靠条件里有两条：电子签名制作数据用于电子签名时属于电子签名人专有，签署时电子签名制作数据仅由电子签名人控制。把落章留给有印章权限的人本人做，这两条才说得清是谁在控制。

在电子签章平台里，审批通过后分两种情况处理：如果审批人自己就有这枚印章的权限，审批通过后要本人再做一次签署意愿认证才完成盖章；如果审批人自己没有印章权限，签署任务里的印章状态会显示为待用印，系统将有印章权限的印章管理员拉进该签署任务，由印章管理员核对审批记录后完成签署意愿认证并盖章。

企业在分配系统账号权限时，印章保管与调用权限只绑给具体的印章管理员或授权审批人，不把印章权限授予用印审批 Agent 的服务账号，也不允许 Agent 借用员工账号跳过意愿认证；关于替员工调用系统时怎么管身份与权限边界，见 <NoteLink slug="agent-acting-on-behalf-of-user">Agent 身份认证：替员工调系统用谁的权限</NoteLink>。

## 盖完怎么留痕与文件改动怎么防

第十三条列的可靠条件还有两条：签署后对电子签名的任何改动能够被发现，签署后对数据电文内容和形式的任何改动能够被发现。所以盖完章的文件要能验出有没有被改过，归档时把验证结果一起存下来。

用印审批 Agent 把每一单从发起到落章的完整链条归档留存，记录里包含经办人提交的原始申请单、定稿比对结果、各级审批人同意或驳回的意见与时间戳、签署意愿认证记录、实际盖章的印章管理员以及最终加盖电子签章的归档文件。如果在盖章前发现经办人替换了审批过的定稿，可以配置成作废当前待用印任务，经办人带着修改说明重新发起审批。

## 用印审批 Agent：常见问题

### 审批人已经点同意了，为什么盖章时还要再做一次认证？

点同意是内部审批，表示同意用这枚章。签署意愿认证是落章那一刻确认操作的人就是有权限的本人。《电子签名法》第十三条把「签署时电子签名制作数据仅由电子签名人控制」列为可靠条件之一，这次认证留下的记录能说明盖章时是谁在控制。

### 审批人没有印章权限，批完以后章怎么盖上去？

审批人没有印章权限时，点完同意后文件上的印章位置会显示为待用印状态。用印审批 Agent 按规则把持有该印章权限的印章管理员拉进这条签署任务，由印章管理员核对前置审批已全部通过后，由其本人完成签署意愿认证并盖下印章。

### 电子签章能让 Agent 直接盖吗？

不能。电子签章受《电子签名法》约束，可靠的电子签名要求签名制作数据专属于电子签名人且签署时仅由签名人控制。印章权限不要授予用印审批 Agent 的账号，Agent 只能做申请要素核对、定稿比对、审批路由和归档留痕，最后的签署意愿认证和落章动作要由有权限的人亲自完成。
