银行对账 Agent 负责做流水勾对、把没对上的条目按四种未达账项归好类、起草银行存款余额调节表，并标出每笔差额的可能原因和待补凭证；查凭证、取回单和定差错由财务人员分工完成。企业已付银行未付的条目由出纳去问收款方，银行已收或已付但企业未记的条目由总账会计取回银行回单后再入账；调节后两边仍不平，或单笔挂账超过企业定的天数还没消，交由财务主管定性处理。

## Agent 能对到哪一步

企业的银行存款日记账要定期和银行对账单核对，至少每月一次。两边余额出现差额，就要编银行存款余额调节表。

有的财务软件支持自动勾对，银行账号、币别、金额相等且方向相反是必选条件，结算号、对方户名、对方账号、业务日期和摘要可以按需加进匹配条件；自动没对上的进入手工勾对。银企直联的场景可以配置成先按对账码匹配，再按金额、日期、结算号或摘要匹配。

银行对账 Agent 接手的是自动勾对后剩下的未匹配条目。它逐条比对日记账与对账单明细，按四种未达账项预先分好类，起草银行存款余额调节表，并给每条写出可能原因和要找的结算凭证。

## 四种未达账项分别谁去查

两边余额有差额，原因分未达账项和记账出错两类。未达账项是企业和银行拿到结算凭证的时间不同、记账时间不一致造成的。Agent 把没对上的条目按四种类型分好后，按下面的岗位分工去查。

- **企业已收、银行未收**：企业已凭结算凭证记了收款，银行对账单还没体现。Agent 标出对应分录和结算号，由出纳核对手头结算凭证并向银行查入账进度。
- **企业已付、银行未付**：企业已记付款而银行未付，例如开出的支票对方还没去兑。Agent 把条目推给出纳，由出纳去问收款方；这类条目常来自前端付款环节，付款侧的关口见 <NoteLink slug="ap-invoice-agent-payment-control">应付账款 Agent 从对账做到付款，中间哪几道关不能省</NoteLink>。
- **银行已收、企业未收**：银行已入账而企业未记，例如银行代收货款已到账、企业还没收到凭证。Agent 提炼对方户名与金额提示总账会计，由总账会计去取银行回单，拿到回单才入账。
- **银行已付、企业未付**：银行已扣款而企业未记，例如银行扣的费用。同样由总账会计去取银行回单，核实费用后按凭证入账。

## 调节后还不平怎么办

Agent 起草好银行存款余额调节表后，出纳和总账会计先看调节后的两边余额是否相等。调节后两边余额相等，通常说明双方记账没有错，这个余额是企业实际能动用的存款数。

调节后两边余额还不相等，通常是未达账项没查全，或者一方、双方账记错了，要继续追查。出纳和总账会计先核查未匹配流水有没有漏归类，再核对日记账录入的金额和方向有没有记错。

初查后仍不平，或者某条未达账项挂了超过企业定的天数还没消，交财务主管拍板，定下来是内部记账错误要更正，还是要找银行查。

## Agent 不碰哪几件事

银行存款余额调节表只用来核对，不属于原始凭证，不能作为调账、补记的记账依据。未达账项本身不做账务处理，等结算凭证到了再正常入账。银行对账 Agent 只管勾对和起草调节表，不能拿调节表去补记账，也不能自己改分录。

匹配规则的宽严同样不让 Agent 自己动。有的财务软件支持按需叠加结算号、对方户名、对方账号、业务日期和摘要；匹配条件放得越宽，错配越多。匹配规则由财务主管定，改动留记录；一旦勾错了对，要能取消勾对并查到是谁改的规则，回滚与追责做法见 <NoteLink slug="agent-rollback-and-accountability">Agent 已经执行出错了，怎么回滚、责任算谁的</NoteLink>。

## 银行对账 Agent：常见问题

### 银企直联已经能自动勾对了，还要 Agent 做什么？

银企直联场景可以配置成先按对账码匹配，再按金额、日期、结算号或摘要匹配。自动勾对没对上的部分仍会落入手工勾对环节，银行对账 Agent 处理的就是这部分剩余差额：逐条比对摘要和往来信息，按四种类型预先分拣，标出待补凭证并生成调节表草稿，交给出纳和总账会计核实。

### 调节表编平了，账面存款余额要跟着改吗？

不改。调节后两边余额相等，代表双方记账通常无误，调节后的数字是企业实际能动用的存款数，只用来核对。银行存款余额调节表不能当作原始凭证用来调账或补记，日记账和总账上的分录都要等拿到正式结算凭证或银行回单后才入账。

### 未达账项挂了很久没消，要怎么处理？

先按未达账项的四种类型分清是哪一侧还没入账：企业已收或已付而银行未记的，由出纳核对结算凭证、联系收款方或银行追问进度；银行已收或已付而企业未记的，由总账会计去取银行回单。挂账超过企业定的天数仍没消掉的，交财务主管判断是否存在记账错误或需要找银行核实；结算凭证到齐之前不在账上直接调平，调节表也不作记账依据。
