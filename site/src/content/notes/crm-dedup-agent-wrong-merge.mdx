客户数据去重一旦合错两家独立公司，管理文档没写撤销办法，拆回来基本靠人工：重新启用被停用的从记录，把联系人、商机、活动逐条挂回去，被覆盖的字段靠合并前的导出留底或变更记录找回。因此把控重点在合并前：Agent 只出疑似重复清单和比对理由，名称相近但统一社会信用代码不同的不算重复；CRM 客户合并由客户数据负责人确认，一次只合一组，合并前先把两条记录和下属子记录完整导出留底。

## Agent 凭什么判重复

销售运营清理系统里的重复客户时，先让 Agent 跑一遍全量或新增客户表。按照主流客户关系管理平台的官方管理文档，平台可以通过设定重复检测规则来识别潜在的重复记录。落到企业日常管理里，Agent 的任务是筛出疑似重复清单，并逐组写明判定理由，列出两条记录在客户名称、税号或统一社会信用代码、注册地址、联系电话哪几项上一致。

光看公司名字长得很像，不能直接当成同一家企业。集团下属的不同分子公司、同地名的关联企业，或者字号相近但没有关系的两个主体，在系统里名称可能很接近。规则里写明一条：只要两家企业的统一社会信用代码或税号不同，就算名称、地址、电话有重合，也不算重复客户，只允许标记为关联企业或备注说明，不准放进待合并清单。外联动作在发出前怎么设人工把关，见 <NoteLink slug="crm-outbound-agent-send-approval">CRM 外联 Agent 发信前，哪几步要留人工审批</NoteLink>。

## 合并前要留什么底

根据主流客户关系管理平台的官方管理文档，执行合并时要选定一条主记录，另一条作为从记录；合并完成后，主记录会继承从记录的全部子记录，从记录本身被停用；操作时可以选择保留从记录里哪些字段的数据，被选中的字段数据会复制到主记录上，从记录原本关联的备注、活动等都会挂到主记录名下；另外，系统不允许把数据合并进一条已经处于停用状态的记录里。这两份官方管理文档都没有写怎么撤销一次已经完成的合并。

既然这两份文档没写撤销办法，合并前的留底就是拆回来的主要依据。在点击执行 CRM 客户合并之前，可以配置成先由 Agent 或管理员把待合并的主记录、从记录本身的所有字段快照，连同两条记录各自名下挂着的联系人、商机、跟进活动、合同附件清单，原封不动地导出一份表格或备份文件存档。没有这份合并前的快照，一旦两条记录混在一起，事后根本分不清哪条商机、哪个联系人原本属于哪一家。

## 合错了怎么拆

如果发现 Agent 把两家名字相近的不同公司合成了一家，销售运营第一步是立刻停掉 Agent 的合并权限，防止它继续按同一套错误逻辑往下合；接着去查操作记录，看同一条判重规则下还合并了哪些客户，全部拉出来排队核查。主数据被改错后怎么顺着记录追查，见 <NoteLink slug="erp-master-data-agent-change-trace">ERP 主数据修改交给 Agent，改错怎么追？</NoteLink>。

具体拆回来的动作全靠人工一步步倒推：

- **重新启用原从记录**：去系统后台找到那条在合并时被自动停用的从记录，将它的状态重新改回启用，恢复它作为独立客户档案的资格。
- **逐条迁回子记录**：对照合并前导出的留底清单，把当时从原从记录名下自动转移到主记录里的联系人、在谈商机、历史跟进活动和备注，一条一条改回原从记录名下。
- **恢复被覆盖的字段**：检查主记录上有哪些电话、地址、行业分类或负责人字段在合并时被从记录的数据覆盖了，依据合并前的导出留底或系统的字段变更记录，把主记录自己的原始数值填回去。

## 谁确认 CRM 客户合并

为了让合并错误少发生，职责边界要切干净：判重和整理清单交给 Agent，合并由专门的客户数据负责人确认。Agent 每天或每周跑完比对后，只生成一张待确认的疑似重复卡片，左边列主记录、右边列从记录，中间标红两边的差异字段和各自挂着的子记录数量。

客户数据负责人加上对应的销售负责人一起看这张卡片，核实工商信息和业务往来后，确认确实是同一家公司被重复建档了，再由客户数据负责人点确认执行，而且每次只合并这一组，不做批量自动合并。合并动作完成后，把留底文件、确认人姓名、确认时间和合并理由一起归档备查。

## 客户数据去重：常见问题

### 客户数据去重多久做一次？

企业按照自己日常新增客户记录的录入量来定清理周期，不定统一频率。有的团队在新建客户入库时先让 Agent 做一次实时判重拦截，存量库则按业务节奏定期拉出疑似重复清单，交由客户数据负责人分批核对处理。

### 合错的记录拆回来后，销售跟进记录会丢吗？

合并时从记录关联的备注和活动都被挂到了主记录下面，记录本身还在系统里，但混在了主记录的时间线里。往回拆的时候，要对照合并前导出的留底清单逐条核对，把属于原从记录的销售跟进记录一条条重新关联回去；如果合并前没留底，就只能由跟进的销售人员自己凭记忆和聊天记录一条条认领。

### CRM 客户合并能让 Agent 自动做吗？

不能让 Agent 自己直接点合并。查找疑似重复记录、比对名称与统一社会信用代码、导出合并前留底快照这些准备工作可以交给 Agent 自动跑完；但最终决定哪条当主记录、保留哪些字段、以及按下 CRM 客户合并确认键，都要由客户数据负责人核对后人工操作。
