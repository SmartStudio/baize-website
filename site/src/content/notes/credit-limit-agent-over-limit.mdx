客户信用额度的调整建议由 Agent 按回款、逾期和订单趋势核算，额度修改与超额发货放行都由人工审批。长期额度由信控专员发起，财务经理按企业自己定的金额档批复；发货前触发超额或逾期的单据先挂起，销售填理由申请特批，超标小的由财务经理批，超标大的或带逾期的升到财务负责人或总经理签字。

## Agent 调额看哪些数

信控专员或应收会计定期复核客户授信时，Agent 汇总该客户近期的回款记录、历史逾期情况与在手订单趋势，生成调额建议单。建议单列明当前授信总额、已占用金额、近期回款速度和未结应收构成，把上调或收紧额度的计算依据摊开写清，方便信控专员对照业务实况做初审。

企业的已用额度随业务单据流转实时变化。新提交的销售订单、已开具的发货通知单、已确认的销售出库单和挂账应收都会占用额度；财务完成收款核销，或者仓库办完退货入库后，对应金额才会释放出来。Agent 核算可用余额时把这些未完结单据一并算进去，防止只看财务应收总账漏掉刚接进来的待发订单。

Agent 算完调额建议只提交草稿，不自己改动主数据里的授信上限。长期额度由信控专员结合销售反馈的交易背景发起调整申请，财务经理按照企业自己定的金额档审批生效。财务给业务划定授信额度与价格边界的做法，见 <NoteLink slug="sales-quote-agent-discount-floor">销售折扣 Agent 自动让价，底线谁来设？</NoteLink>。

## 发货前额度怎么卡

有的管理软件支持把信用控制挂在销售订单、发货通知单、销售出库单上，在单据提交或审核时触发检查。有一种配法是接单放行、发货卡紧：客户额度超标时允许销售先把订单录进去安排备料，到了发货通知或出库环节再严格拦截；没超额的单据走正常审批，触发超额发货的走领导审批，批过了仓库才准出库。企业按客户风险等级配置检查规则时，控制强度常见分成四档。

- **预警提示**：单据提交时弹窗提醒信控专员和销售关注余额，单据继续往后流转。
- **权限特批**：单据停在当前审核节点，转给有特批权限的管理人员批过后才能放行。
- **取消交易**：当前这张超标单据直接终止交易，后续不再进入备货或发运队列。
- **冻结客户**：冻结该客户编码，名下所有新建和在途业务单据都不能提交。

检查维度不止授信总额，有的工具还支持同时查逾期天数、逾期金额、逾期占比和单笔限额。配置这类校验后，哪怕总额度还有剩余，只要旧账超出企业定的天数或逾期占比越线，发货单据同样挂起。Agent 在发货前逐项查验额度和逾期状态，超标时把单子挂起，起草包含客户名称、超标金额、逾期情况、销售说明的理由和预计回款日的特批申请；哪些调用放行、哪些拦下交给人审，见 <NoteLink slug="agent-tool-call-auto-approval-rules">Agent 工具调用自动审批：哪些放行、哪些拦下</NoteLink>。

## 超额发货谁批到哪一级

Agent 把起草好的特批申请推给负责该客户的销售，销售核实客户要货背景、补齐预计回款安排后提交审批。销售和销售负责人只能发起申请并确认业务真实性，不能自己审批名下的超额发货，放行权统一收归财务与公司管理层，按企业自己定的金额档和逾期情况分级签批。

- **小额且无逾期**：过往回款正常、账上无逾期，本次超标金额落在小额档内的，由财务经理审批。
- **大额或带逾期**：超标金额跨过企业自己定的金额档，或者账上挂着未结清的逾期款，升到财务负责人或总经理签批。
- **阶段性临时额度**：客户旺季集中提货需要短期放宽的，有的工具支持设临时信用额度，按企业自己定的金额档批完后写明到期日，到期失效。

## 特批之后怎么回看

每笔特批放行的单据都留存记录可查，包含客户名称、关联单号、超标金额、特批人和处理日期。信控专员或应收会计定期调出特批台账，逐笔核对回款兑现情况。

到了销售当初填报的预计回款日，Agent 核对该笔特批对应的应收款有没有按时到账核销，把未兑现的名单推给信控专员和财务经理。按期结清的客户维持原有授信档位；特批放行后拖延回款的客户，信控专员在下一次评估时下调长期额度、取消临时额度资格，或者把控制强度从特批档调高到冻结档，收紧后续接单与出库权限。

## 客户信用额度：常见问题

### 客户刚打了款还没核销，额度没释放能先发货吗？

按常见配法，已用额度要等收款单入账后才会释放。客户刚汇款但财务还没走完认款核销时，Agent 查到的可用余额仍按未收款状态计算，不会凭销售传来的转账截图放行出库。急需发运的单子，要么请应收会计核实银行到账记录后优先办完收款入账释放额度，要么按超额流程提交特批。

### 总额度还有剩余，但有一笔旧账逾期了，还能正常出库吗？

这要看企业配置的检查维度。把逾期天数、逾期金额或逾期占比纳入发货校验后，只要名下旧账超出了设定的阈值，哪怕总授信还有余额，发货通知单和出库单照样会挂起。带逾期记录的特批层级比单纯额度不足更高，按分级规则升到财务负责人或总经理签批。

### 大客户急着要货，超额发货能先发后批吗？

超额发货不走先发后批，仓库没见到系统里的特批通过状态不出库。大客户临时急单可以走加急特批通道，Agent 先把客户账面数据、超标金额和历史回款明细整理成卡片推给审批人，有权限的财务经理或负责人在线核实后即时签批；需要连续多批提货的，按企业自己定的金额档申请带到期日的临时信用额度。
