人力资源部门上线员工问答 Agent 解答假勤政策，算法依据现行制度文件提供指引，帮助员工自助查询病假、婚假与调休规则。一旦工具给出的答复出现偏差，员工依据错误信息安排了行程或提出休假申请，企业无法把管理责任推给软件。企业需要提前划定工具回答与人工介入的边界，设定版本溯源与补救通道，由人力专员针对个案妥善核实。

## 算法只答通用条款，个人额度转交人工

员工在即时通讯软件的对话窗口询问产假包含多少天法定节假日，员工问答 Agent 调取考勤管理办法的文字条款输出解释。工具在回答通用规则时响应迅速，能够列举不同司龄对应的法定年假天数基准，以及婚假申请需要的证明材料。

涉及个人假期余额计算与特殊工时审批时，系统把对话切换给人工座席，避免算法因缺少工龄折算数据而给出错误判断。对外承诺谁来认，见 <NoteLink slug="ai-cs-can-reply-vs-who-owns-liability">AI 客服合规：能自动回复了，承诺谁来认？</NoteLink>。员工追问自己剩余几天带薪年假或者能否申请跨年顺延时，对话框弹出人力服务台工单链接，由负责薪酬考勤的人力专员核对考勤系统数据后再予确认。通用制度查询由程序分担，涉及个人权益与审批裁量的具体事项由业务岗位承接。

## 每一条答复都附带文件版本与条款编号

员工发送调休有效期咨询，系统界面在文字下方显示考勤管理制度条款出处以及发布年份。算法在截取制度段落作答时，同步展示制度编号与生效日期，方便员工直接核对制度原文。

规章版本怎么维护，见 <NoteLink slug="enterprise-context-engineering">企业上下文管理：AI 时代不脱节的基础设施</NoteLink>。人力资源部门发布新版休假管理办法后，系统管理员在知识库后台将旧版文件标记下线，载入经过发文流程的新规章。算法被限定只在当前生效的文件里检索，防止员工获取到失效的假期待遇信息。

## 发现回答失误后人工介入核实补救

员工按照对话截图提交了年假冲抵探亲假申请，审批主管发现条款理解存在偏差，把工单转给人力专员。人力专员核对聊天记录，确认算法把特定岗位的专属福利条款误推送给普通岗位员工。

二〇二四年二月，加拿大不列颠哥伦比亚省民事纠纷仲裁庭在 [Moffatt 诉加拿大航空案](https://www.canlii.org/en/bc/bccrt/doc/2024/2024bccrt149/2024bccrt149.pdf) 中裁定，加航要为官网聊天机器人给错的丧亲票价政策负责，没有采纳「聊天机器人要为自己的话负责」的抗辩。这是针对外部客户的海外民事裁决，不能直接套用到国内劳动关系争议中，但表明企业很难把官方工具说错的话推给工具自身承担。

人力专员联系该员工说明情况，按照既有制度核对其实际享有的假种。如果员工已经按照工具给出的答复预订了行程，人力部门与部门主管结合业务排班予以协调，可以补办调休手续，或者改成分段休假。人力专员在后台对这条错误问答打上纠偏标签，把这条问答交给维护知识库的同事修正对应内容。

## 调阅问答日志把模糊问题补入正规制度

人力专员在后台导出问答记录，筛选出反复被员工追问的假种关键词。分析发现，多位员工在咨询育儿假与护理假重叠时能否顺延，算法由于现有文件缺少细化条款而给出了含糊的回答。

人力团队把这些高频模糊点整理成条款补充建议，提交规章评审会议审议。修订后的实施细则增加了具体算薪与假期间隔说明，经过公示程序后重新录入知识库。

## 员工问答 Agent：常见问题

### 员工截图拿错答作为请假凭证，HR 认不认？

HR 先调出原始问答记录核对当时 Agent 怎么答的，再按制度和员工的具体情况处理；员工已经按错误答案做了安排的，由 HR 和部门主管商量补救办法，有争议的找法务。

### 怎么限制 Agent 不去编造没有的假期政策？

企业在知识库检索设置中开启严格匹配模式，限定算法只在上传的制度原文范围内提炼内容。当员工提问超出已录入文件的范围时，系统预设标准回复告知当前无对应制度记载，并提供人工服务台转接入口，防止算法自行推导编造。

### 员工手册更新了，Agent 怎么跟上？

员工手册完成民主程序并向全员公示后，管理员将旧版切片文件整体替换。算法重新建立索引，用常见问题清单重新问一遍，核对新旧条款交替处的回答，确认新规则生效后再向员工开放查询。
