交期承诺 Agent 负责按实时库存、在途物料和车间可用产能算出可承诺量，给出建议交期；最终向客户发出的正式交期承诺，由点击确认的销售或计划员负责。常规标准单在可承诺量范围内由销售核对后发给客户；遇到紧急插单、需求超出可承诺量或定制大单，必须转生产计划员复核签字；一旦订单晚交，调取发出承诺时保存的系统快照，查清是底层数据失真、后续排产被插单挤占，还是业务员自己改短了交期。

## 建议交期怎么算与对外承诺谁来拍板

客户询单或下单后，交期承诺 Agent 自动去仓储、采购和生产排程系统拉取现有库存、有明确到货日期的在途物料，以及对应产线在未来各时间窗内的剩余可用工时。Agent 用现有库存加有明确到货日期的在途，减去安全库存，再减去已承诺、已锁定的订单占用，得出可承诺量，再叠加上下料检验、包装及物流在途天数，生成建议交期卡。

建议交期卡只推到内部工作台，不能由系统直接外发给客户。对于需求数量落在现有可承诺量以内、工艺路线固定的常规订单，负责该客户的销售人员核对客户收货窗口与合同条款后，点击确认即可生成正式交期回复；对外发信前为什么要留人工审核关口，见 <NoteLink slug="crm-outbound-agent-send-approval">CRM 外联 Agent 发信前，哪几步要留人工审批</NoteLink>。未经人工点击确认的建议日期，一律不作为正式合同承诺。

## 哪些特殊订单必须转计划员人工确认

日常接单时常会遇到超出常规核算边界的订单，这类单据交期承诺 Agent 只负责标出缺口明细，必须转给生产计划员人工核准。第一类是需求量超出当前可承诺量的订单，需要跨批次备料或向供应商追料；第二类是要求比标准周期更短的加急插单，一旦塞进现有排程，就会挤占其他已承诺订单的产能或公用物料；第三类是首次投产的新品或定制单，工时和良率参数还没跑稳。

碰到这三类订单，交期承诺 Agent 在工作台里列出物料缺口清单、受影响的在制订单号以及需协调的产线工段，自动挂起对外回复流程并转交计划员。计划员评估能否通过加班、外协、调拨替代料或同其他客户协商微调交期来腾出产能，确认可行后在系统里填入核准交期并签字，销售才能拿这个日期答复客户。

## 订单晚交了怎么按记录查清责任

订单一旦发生逾期，企业直接调出交期承诺 Agent 保存的决策快照。每一笔订单在人工确认、对外发出承诺的那一刻，系统都会把当时的库存余额快照、在途采购单预计到货日、产线负荷表版本、Agent 给出的建议交期，以及最终人工确认发出的承诺交期完整封存。Agent 执行结果出偏差时怎么回溯与定责，见 <NoteLink slug="agent-rollback-and-accountability">Agent 已经执行出错了，怎么回滚、责任算谁的</NoteLink>。

复盘时对照快照分三条线查责：第一，销售未按建议交期回复，也没走计划员特批就私自承诺更早日期，责任在销售；第二，发出承诺时按建议执行，但事后仓库盘亏、虚报库存，或采购未更新供应商延期信息导致底表失真，责任在数据维护岗；第三，发出承诺时数据准确，但后续设备故障、质量返工或插入急单挤占了产能，归入生产波动或计划变更责任。

## 预计要晚交时怎么预警与怎么提前通知客户

交期承诺 Agent 在订单锁定后，每天持续跟踪关联采购单的收货状态和车间工单的报工进度。只要上游关键物料晚到、工序报工延误超出设定的阈值，或者质检出现批量不良导致可用成品不足，系统立即向计划员和对应销售发出延期预警。

收到预警后，计划员先重算最早可补救的发货时间，评估能否拆批先行发出一部分现货。确认无法按期全量交付时，Agent 根据最新排产结果起草客户沟通草稿，写明受影响品项、可先行发货数量及调整后的预计送达日期。销售核对草稿后，赶在原定交期前主动联系客户协商分批交货或改期。

## 交期承诺 Agent：常见问题

### 两个销售同时询同一批现货的可承诺量，会卖重吗？

不会卖重，前提是在系统里配好预占锁库规则。销售只做初步询期时，交期承诺 Agent 给出的可承诺量带有时效提示，不锁定实物库存；一旦客户明确下单意向、销售点击申请锁库，系统按先到先得原则生成带有效期的临时预占额度，并在其他销售查询时自动扣减；超时未转成正式订单的，预占额度自动释放。

### 供应商在途物料临时晚到了，已经报给客户的交期怎么改？

采购员在系统里更新在途采购单的预计到货日后，交期承诺 Agent 自动扫描所有绑定该批物料的销售订单，重新核算发货时间。重算后预计晚于原承诺交期的订单，系统立刻标红并推给计划员；计划员先查有无替代库存顶上，确实顶不上的，由销售拿着新交期提前找客户沟通改期。

### 可承诺量不够时 Agent 怎么报？

当客户需求数量大于当前可承诺量时，交期承诺 Agent 会自动拆出分批交付方案供内部确认，既不直接拒单，也不笼统只报一个最晚日期。系统先算出利用现有库存和近期在途料能满足的首批可承诺量及最早发货日，再按标准采购提前期和后续排产空档算出剩余缺口数量的第二批预计交期，同时把缺口明细推送给生产计划员核准。
