Agent 出网管控的常见基线，是沙箱默认拒绝所有出网，再按域名白名单放行。白名单开多宽按任务定，不按整个 Agent 笼统放开：先列这个任务要访问的模型接口、内部接口、依赖源和存储地址，从空清单起步跑一遍，看拦截记录补齐；能用具体子域名就不用通配；代码托管、网盘这类能写能传的宽域名默认不放或只放只读方法；内网私网网段单独写进拒绝清单；白名单变更走安全负责人审批留痕，并定期按日志回收不用的域名。

## 先列任务到底要连哪些地址

配出网策略前，先梳理单次任务要连的外部目标，通常包括模型接口、内部业务接口、软件依赖源和存储地址。如果沙箱接入了外部工具服务，服务要连的外部地址同样要进清单，接入前的安全审查见 <NoteLink slug="mcp-server-security-review">MCP 安全风险怎么查：接入前先审哪 4 项</NoteLink>。

下发配置前要看清平台规则优先级。有的平台要求域名白名单配合拒绝全部一起配置，只配白名单不配拒绝，白名单不生效，其余流量照样放行；有的平台允许规则优先于拒绝规则，同一目标两边都命中时放行，配置前要先核对清楚。

还要注意存储挂载和内网地址。挂了对象存储或网络文件系统的沙箱，调整出网策略前要先放行对应存储地址，否则挂载和读写会断。放行的主机名在连接前会先解析一次，解析到回环地址、云元数据地址的会被拒绝；但私网网段默认不拒，运维要单独把私网网段写进拒绝清单。

## 白名单从空开始怎么补

找全要放行的域名往往要反复试几轮。团队可以先在测试环境跑通任务试错，测试环境搭法见 <NoteLink slug="agent-sandbox-test-vs-prod-data">Agent 测试环境：接 CRM 前先用模拟数据？</NoteLink>。补齐白名单可以分三步：

- **分阶段配置**：可以先从源码托管、包管理等常用依赖预设清单起步，再逐步收窄；安装依赖的准备阶段可以开网，Agent 执行阶段默认断网，两个阶段分开配。
- **看应用层报错补齐**：被拒绝的连接在沙箱里有时仍显示连接成功，判断有没有放行要看应用层返回；拦截时有的代理会返回明确的拒绝提示，对照拦截记录把缺失的子域名补进清单。
- **按任务动态收紧**：策略在沙箱创建后还能更新，可以按任务动态收紧出网范围，能写具体子域名就不用通配子域名。

域名过滤一般只覆盖 HTTP 和 HTTPS，靠 HTTP 的 Host 头和 TLS 握手里的主机名判断；其他端口只能按 IP 或网段过滤，基于 UDP 的协议有的不支持按域名过滤。不走代理的程序会直接连不上。此外，代理默认不解密 HTTPS 内容，只看客户端报的主机名，存在被域前置绕过的可能。

## 宽域名和写方法为什么要单独卡

沙箱开网面临四类风险：网页内容里的提示词注入、代码或密钥外泄、下载恶意或有漏洞的依赖、引入有许可证限制的内容。放行一个公共代码托管站点，等于允许 Agent 往任意仓库推送代码，形成数据外泄通道。

针对宽域名和凭据外泄风险，可以配置三道关卡：

- **只放行只读方法**：只放行需要的域名和 HTTP 方法，把请求限制在 GET、HEAD、OPTIONS 等只读方法，POST、PUT、PATCH、DELETE 等写类方法一律拦下。
- **凭据不进沙箱**：密钥和令牌不直接放进沙箱，沙箱里只看到占位值，出网时由代理替换成真值。
- **审查输出与日志**：定期审查 Agent 的输出内容和工作日志，排查异常外发或违规依赖。

## 白名单谁批与怎么定期收窄

开发团队在测试环境摸清任务所需的域名和 HTTP 方法后，连同用途说明提交给安全负责人审批。代码托管、网盘、通用搜索这类宽域名默认不放行，确需读取公开资料的只批只读方法，审批通过并留存记录后才上线。

规则运行期间，运维和安全团队定期核对放行日志和拦截日志，把长期没有命中的域名和过宽的通配规则从域名白名单里删掉，按任务保持最小出网范围。

## Agent 出网管控：常见问题

### 沙箱里调外部接口要用密钥，怎么防 Agent 把密钥发出去？

用凭据不进沙箱的机制。沙箱内部只配置占位值，Agent 读环境变量也拿不到真密钥；当请求发往白名单允许的目标地址时，由出网代理在边界上把占位值替换成真值后再发出。

### 为什么沙箱里看连接显示成功，但接口调用还是失败？

因为被拒绝的连接在沙箱里有时仍显示底层连接成功。代理在收到请求后检查 HTTP 的 Host 头或 TLS 握手主机名，发现不在白名单里才拦截，有的会返回明确的拒绝提示。排查时要看应用层返回内容和代理拦截记录。

### 域名白名单只放了几个域名，Agent 为什么还是装不上依赖？

主要有四个原因。第一，依赖源常有多个下载子域名和镜像地址，只放主域名不够，要看拦截记录补进域名白名单；第二，安装依赖的准备阶段和 Agent 执行阶段最好分开配，准备阶段用常用依赖预设清单开网，执行阶段再断网；第三，有的命令行工具不走代理，不走代理的程序在沙箱里直接连不上；第四，若沙箱挂了对象存储或网络文件系统，调整策略前要先放行对应存储地址，否则读写会断。
