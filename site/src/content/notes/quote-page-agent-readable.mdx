报价页挂在企业官网上公开对外，买方的比价 Agent 抓走页面文字后，读到的价格可能被当成这家企业对外的价格口径，所以上线和改价都要有人签字。销售运营或定价负责人定档位和计费口径，财务核对税费、币种、公开折扣与生效日期，法务审定有效期和「以合同为准」的说明，市场部网站负责人只按签好的版本发版，不自己改数。

## Agent 从报价页读什么

采购方让 Agent 去搜集供应商方案时，读的主要是官网价格页直接返回的文字，图片、折叠栏和弹窗里的内容不一定读得到。官网落地页在面对机器比价时整体该怎么改，见 <NoteLink slug="agent-buyer-b2b-landing-page">Agent 买家替企业比价时，B2B 落地页还按人来写吗？</NoteLink>。到了公开价格页这一环，如果套餐单价被做进静态海报图、藏在需要手动点击才展开的月付年付切换按钮里，或者完全靠页面加载后脚本生成，外部抓取工具可能读不到价格，或者只读到默认状态下的一部分。

可见文字写好以后，网站团队还可以参照搜索引擎的结构化数据文档，在页面底层代码里补上一层机器可读报价，把产品名称、报价档位、价格、结算币种、价格有效期和计价单位按规范字段写清楚。这层结构化数据要和页面上肉眼看见的文字完全对齐，页面上没写的价格或内部优惠口径，不能单独写进结构化数据。

## 价格口径要写清哪几项

每一个套餐或报价档都要把这些项集中写在同一块区域里，涵盖套餐名称、价格、币种、计费周期、按账号或按用量或按次的计价单位、适用对象、包含的服务内容、超量或功能限制条件、是否含税、是否需要联系销售报价，以及当前版本的生效日期或最后更新日期。字段散落在页面各处，抓取工具就容易把甲套餐的单价和乙套餐的包含额度配错。

写具体金额时用完整句子，说清这笔钱对应的计费周期和计价单位。页面上只写一个「起价」和金额，抓取工具分不清这笔钱是固定包年总价、单账号基础单价、限时促销折后价，还是按年付费折算到每个月的均摊价。遇到面向大客户的定制价或企业档位，价格栏也别留白或只画横线，直接在原位置写清「需要销售报价」，顺带列明销售核算价格时主要看并发规模、部署方式还是服务等级等哪些因素。

## 改价时哪几处要一起改

官网价格页很少只有一张卡片，顶部摘要、中部价格卡片、下方的套餐功能对比表、页面底部的常见问题解答，再加上代码里的机器可读报价和页脚更新日期，往往同时写着价格信息。业务部门调整公开定价时，市场网站团队要把这几处列成一张联动核查表，发版时一次性全量替换；漏改任何一处，同一张网页上就会同时挂着新旧两种价格，买方工具抓回去就会引发报价争议。

新版本上线后，市场部和销售运营再按外部抓取的方式抽查一遍网页直接返回的文字和底层结构化数据，核实外部工具实际读到手的是不是刚签批的新价格。每次调价都要在内部台账里记下版本号和生效日期，替换下来的旧版活动价格页或历史专题页要么直接下线，要么在醒目位置标明已失效，避免搜索引擎缓存或旧链接继续往外传过期口径。

## 谁签字上线

公开价格页上的条件会成为后面商务谈判的起点，签字按职责分开。定价负责人或销售运营负责敲定各档套餐名称、金额、计价单位和功能边界；财务团队核准页面标示的价格含不含税、用什么币种结算、年付或批量公开折扣怎么折算，以及新价格从哪一天起生效；至于客户找销售单聊时的私下让价空间怎么管，见 <NoteLink slug="sales-quote-agent-discount-floor">销售折扣 Agent 自动让价，底线谁来设？</NoteLink>。

法务看价格有效期的写法和页面措辞会不会被当成对外承诺，并在页面显眼处写上「公开页面仅供选型测算参考，最终成交价格与权利义务以双方签署的正式合同及盖章报价单为准」这类边界说明。市场部网站负责人在最后一步，只按定价、财务、法务会签完的定稿更新可见文字与机器可读报价，不在后台自己改字改数。

## 报价页：常见问题

### 企业版没有固定标价，公开报价页怎么写才不会被漏抓？

不要把企业版的价格栏空着或者只放一个预约演示按钮。直接在企业版卡片的价格位置写明「需要销售报价」，紧接着用完整短句列出该档位包含的专属能力，以及核算价格时依据的账号规模、数据量、部署环境或服务响应等级等因素，让买方比价工具能把企业版照常收进候选清单并转交人工询价。

### 促销活动结束后，旧的活动报价页怎么处理？

促销期一过，市场部网站负责人按预先签好的失效日期同步撤下活动价标识，把价格卡片、对比表、常见问题和底层结构化数据全部切回日常挂牌价，并更新页面日期。专门为单次促销搭的独立落地页要么直接下线回收，要么在首屏文字里写明该促销方案已结束失效，防止外部工具继续抓走过期低价。

### 机器可读报价和页面上的价格对不上，算哪个？

发现两边对不上时，网站负责人先下线有冲突的模块或立刻按内部会签定稿修正。内部核查以定价、财务、法务共同签过字的版本为准；对外沟通则依据页面事先声明的规则，以正式盖章报价单和书面合同为准。改完后还要倒查是卡片、对比表、常见问题还是底层机器可读报价漏了同步，把漏掉的位置补进后续的改价必查清单。
