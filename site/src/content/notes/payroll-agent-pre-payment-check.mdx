算薪 Agent 算出的月度工资表不能直接连银行接口打款，发放前必须走完三道人工把关：薪酬专员先逐条处理系统标出的异常记录，财务会计复核科目汇总金额与资金计划，最后由人力资源负责人与财务负责人签批放行。发薪后如果发现漏算或错算，按公司薪酬制度走补发或协商扣回流程，所有改数、签批与补差原因全程留存记录。

## 算薪 Agent 怎么汇总数据与标异常

每到算薪窗口期，算薪 Agent 自动从考勤系统、绩效系统、人事台账和社保公积金申报表里拉取当月数据，按预设公式算出每个人的应发工资、各项扣款、个人所得税和实发金额。为了验证 Agent 在不同考勤折算和计税边界条件下算得稳不稳，上线前怎么跑多轮测试，见 <NoteLink slug="agent-eval-suite-pass-rate-variance">Agent 评测怎么做：每个任务跑几次才算数</NoteLink>。

算完初表后，算薪 Agent 紧接着跑一轮自动比对，把命中以下四类情况的员工明细标成预警，生成待核查清单：

1. 环比差额超出设定的阈值：员工当月应发或实发金额跟上月相比，增减幅度或差额超出了设定的阈值。
2. 当月发生入转调离：本月新入职、试用期转正、调岗调薪或办理离职结算的人员，涉及按天折算工资或离职结算。
3. 手工导入的浮动项：业务部门用表格手工报送的销售提成、项目奖金、津贴或专项扣款。
4. 极端数值与校验报错：实发工资低于当地最低工资标准、社保公积金扣款异常、银行卡号缺失或校验不通过。

## 薪酬专员与财务各自核什么

工资表进入薪资核对环节后，人力资源部的薪酬专员与财务部的核算会计按职责分工交叉核查，不由同一个人既算又审。

薪酬专员负责看明细、清异常。凡是算薪 Agent 标出的异常条目，薪酬专员必须点开核对原始单据——查考勤假单、核对入职定薪单、比对提成确认表。核实无误后，在条目旁勾选确认并写明原因；发现源数据有误的，退回考勤或业务部门修正源头数据后让 Agent 重算，不直接在结果表上手工改数字。

财务会计负责看总额、对科目。等薪酬专员清完所有明细异常，财务会计做整体薪资核对：核对各部门工资总额环比变动是否合理、账面计提的应付职工薪酬与实发加代扣代缴之和是否平齐、社保公积金单位及个人部分跟扣款回单是否一致。从账单核对到资金划付的内控设计，见 <NoteLink slug="ap-invoice-agent-payment-control">应付账款 Agent 从对账做到付款，中间哪几道关不能省</NoteLink>。

## 发放前谁来签批与银行代发怎么放行

薪酬专员和财务会计确认后，系统锁定当月工资表版本，生成发薪审批单流转给人力资源负责人与财务负责人审批。审批页面直接展示四组数字：本月发薪总人数及上月对比、应发与实发总额及环比差额、各部门薪酬包变动明细、本月人工干预或特殊调整的汇总说明。

负责人签批通过后，系统才会导出加密的银行代发文件，或者把代发指令推入企业网银待授权队列，由出纳提交、财务主管用网银盾复核放行。算薪 Agent 没有直接触发网银划款的权限。

## 发错工资后怎么补发扣回与留记录

即便经过前置核查，偶尔仍会因为考勤迟报、绩效申诉改判等原因在发薪后发现差错。

如果是少发、漏发，由薪酬专员发起补差申请，附上迟到的考勤或绩效审批单，金额超出企业自己定的金额档时走单独补发审批，未超档的经员工知悉后并入下月工资表「补发项」发放。如果是多发，不准私下让员工个人转账退回，必须先与员工沟通确认多发原因与明细，经员工确认后在后续月份工资「扣回项」里抵扣或按指定对公账户退回。每一次重算、异常放行、审批签字与事后补差，都在系统日志里留底备查。

## 算薪 Agent：常见问题

### 考勤数据抓错了导致算薪 Agent 算错，薪酬专员能直接在工资表上改数字吗？

不允许直接在工资结果表上硬改数字。直接在表上改数会导致工资表跟考勤系统、个税申报底稿脱节，下个月比对时还会报错。正确做法是在考勤系统或奖惩表里走修正流程，源头数据改好后让算薪 Agent 重新跑一遍计算逻辑，保证数据链前后一致。

### 每个月很多条环比变动提醒，薪酬专员来得及逐条看吗？

通过分级规则过滤工作量。遇到全员普调、发年终奖或季度奖的月份，算薪 Agent 会把已知合规的批量变动项单独归类合并展示，薪酬专员只需核对奖金导入总表与审批单；真正需要逐人点开核查的，是剔除常规变动后依然超出设定的阈值的个案、手工改数项以及当月入转调离人员。

### 薪资核对要核哪几项？

薪资核对分明细与总额两层。薪酬专员在明细层重点核四项：当月新入职与离职人员的折算天数及基数、调岗调薪人员的生效日期与前后标准、手工导入的提成奖金与扣款审批单、个人环比变动超出设定的阈值的异常条目。财务人员在总额层重点核三项：总人数与总金额的环比变动、实发加各项代扣代缴与应付工资科目借贷是否平衡、个税及社保公积金汇总数与申报表是否一致。
