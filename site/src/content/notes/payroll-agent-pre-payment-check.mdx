算薪 Agent 负责汇总数据和初步试算，发放前要经薪酬专员核明细、财务核算会计核总额、人力资源负责人和财务负责人签批，最后由出纳提单、财务主管复核授权放款。算薪和审薪拆给不同岗位，Agent 不设直接打款权限；发薪后一旦查出少发或漏发，确认后及时补发，不拖到下个发薪日。

## 算完先标出哪些待查条目

月度发薪启动后，企业可以把工具配置成由算薪 Agent 汇总考勤记录、绩效结果、人事台账以及社保公积金扣缴明细，按规则算出每位员工的应发工资、各项扣款、个人所得税和实发金额。由于发薪数据来自不同部门提报，有的工具支持在试算完成后按预设条件做初步薪资核对，把需要人工过目的异常和异动条目单独标出来。企业通常会把下面几类情况设成待查项。

- **环比差额超限**：个人当月应发或实发金额与上月相比，差额超过设定的阈值，需要核实是否有调薪、补发或扣款依据。
- **当月人事异动**：涉及当月新入职、试用期转正、调岗调薪及离职结算的人员，需要人工核验计薪折算与标准切换日期。
- **手工报送数据**：业务部门通过表格手工报送的提成奖金和各类扣款，需要对照原始审批单据核验金额与归属人。
- **明显异常数值**：试算结果出现实发低于当地最低工资标准、员工银行卡信息缺失这类明显不对的数，直接拦下待查。

工具正式投用前，团队可以拿过往历史月份的台账反复跑测，看不同异动组合下算出来的结果稳不稳，具体评测思路见 <NoteLink slug="agent-eval-suite-pass-rate-variance">Agent 评测怎么做：每个任务跑几次才算数</NoteLink>。

## 薪酬专员与财务各自核什么

待查清单生成后，人事侧和财务侧按各自分工展开薪资核对，不由同一个人既算又审。薪酬专员负责逐条处理标出的条目，翻看入离职审批单、调薪通知单、考勤确认表以及业务部门签字确认的提成扣款原始单据，核实每一笔异动有没有据可查。

排查过程中要是发现源头数据错了，比如考勤漏记请假或业务部门报错了提成金额，薪酬专员把问题退回考勤管理岗或对应业务部门改源头单据，改完再重新触发试算，不在工资结果表上直接手改数字。手改结果表会让工资台账与考勤、绩效底表脱节，后续个税累计和离职结算都会对不上账。

薪酬专员处理完所有待查明细并确认无误后，工资汇总表流转给财务核算会计看总额。财务核算会计重点查验各部门工资总额环比变动是否合理、应付职工薪酬科目金额与实发加代扣代缴之和是否对平，并拿社保公积金和各类扣款汇总数跟外部回单比对一致。

## 谁来签批与谁操作放款

明细和总额都核平之后，发薪流程进入管理层签批与资金划付环节。有的工具支持配置会签节点，工资总表连同当月人数变动说明、各部门总额变动说明一并提交给人力资源负责人和财务负责人审阅。人力资源负责人和财务负责人双方签批确认后，才允许导出代发文件。

算薪 Agent 只做数据汇总、试算与异常提示，没有直接打款的权限；付款前的分权与复核关口设计，见 <NoteLink slug="ap-invoice-agent-payment-control">应付账款 Agent 从对账做到付款，中间哪几道关不能省</NoteLink>。企业自己可以在内部制度和网银后台设好权限：代发文件或网银指令由出纳提交，财务主管核对签批单据、代发人数与总金额一致后完成复核授权，银行再执行代发。

## 发错了怎么补差与留痕

即便发薪前经过人工核验，实操中偶尔仍会因为源头迟报异动或单据口径遗漏，在代发完成后才发现金额算错。少发、漏发和多发的处理方式不同，要分开办。

少发、漏发确认后要及时补发，不能拖到下个发薪日。《劳动合同法》第三十条要求用人单位按劳动合同约定和国家规定，向劳动者及时足额支付劳动报酬；《工资支付暂行规定》第七条要求工资在用人单位与劳动者约定的日期支付。企业按上述规定尽快走完补发签批与打款流程。

多发的部分，先和员工说明多发原因和计算明细，按企业的书面制度和员工确认的方式处理，全程留下书面记录；遇到情况复杂、做法拿不准的，先问公司法务或劳动法顾问。有的工具支持把每次重算、放行、签批、补差的操作人、操作时间和原因完整留存，供日后查账复盘。

## 算薪 Agent：常见问题

### 发现源头考勤或提成错了，薪酬专员能直接在工资表上改吗？

不能在结果表上手改。源头考勤或业务提成数据有误时，薪酬专员要把问题条目退回考勤管理岗或提报的业务部门修改源头单据，改完再让算薪 Agent 重新汇总试算。这样才能保证人事底表、工资台账与财务入账凭证口径一致，每次重算的操作人与原因也都留在记录里。

### 工资少发了，能不能并到下个月发薪日补给员工？

不能拖到下个发薪日再补。按《劳动合同法》第三十条和《工资支付暂行规定》第七条要求，用人单位要在约定的日期向劳动者及时足额支付劳动报酬。少发或漏发一经核实确认，薪酬专员与财务核算会计核清差额并走完负责人签批后，就要安排出纳和财务主管及时单独补发到位。

### 薪资核对要核哪几项？

薪资核对按明细层和总额层分开核。明细层由薪酬专员看新入职与离职折算、调薪生效日期、手工导入的提成奖金与扣款，以及超过设定阈值的环比变动；总额层由财务核算会计看总人数和各部门总额环比、应付职工薪酬科目与实发加代扣代缴是否对平，以及个税和社保公积金汇总与申报回单是否一致。
