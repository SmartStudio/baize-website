llms.txt 有用，靠的是「指路」，不是「冲排名」。按 [llmstxt.org](https://llmstxt.org/) 的约定，它是一份放在站点根目录（或子路径）的 Markdown 索引：先用一两段说明站点做什么，再列出优先阅读的页面链接。Agent 打开站点时，能少绕弯。

它不替代 robots.txt。拦不拦 GPTBot、放不放搜索爬虫，写在 robots.txt。也不要指望靠一份 llms.txt 让 Google 或 ChatGPT「更爱引用你」——Google Search Central 写明：Google 搜索（含其生成式功能）不使用 llms.txt，写了不加分也不减分。ChatGPT / Perplexity 是否引用，仍主要看爬虫是否放行、页面有没有可抽取的事实文本；索引文件最多降低找错页的成本。引用侧细则见 <NoteLink slug="chatgpt-perplexity-cite-your-site">怎么让 ChatGPT / Perplexity 引用你的网站</NoteLink>；答案块底座见 <NoteLink slug="what-is-aeo-vs-search-ranking">AEO 是什么？和搜索排名还差在哪一步</NoteLink>。本篇只把索引文件写对。

## 先分清：索引 vs 爬虫门禁

两件事常被写成一本说明书，结果两边都做糊。

1. **llms.txt**：给模型与 Agent 看的 Markdown 目录。链到产品说明、定价、FAQ、合规页等「优先读」的 URL。
2. **robots.txt**：告诉爬虫哪些路径可抓。OpenAI 的 GPTBot（训练相关抓取）与 OAI-SearchBot（ChatGPT 搜索露出）规则互相独立；Perplexity 搜索抓取用 PerplexityBot。这些 Allow / Disallow 只写在 robots.txt。

混写的典型后果：在 llms.txt 里大段抄爬虫规则，索引变得难读；或以为写了 llms.txt 就等于放行了搜索爬虫。门禁没开，索引再漂亮也进不去。

零点击变多以后，索引与答案侧仍要分开验收，见 <NoteLink slug="zero-click-search-still-need-seo">零点击搜索变多了，还要不要做 SEO</NoteLink>。

## 怎么写才算「有用」

按 llmstxt.org 的常见写法，落地时盯这几条：

1. **只输出 Markdown；首行是单个 H1。** 用一两段说明站点是谁、解决什么问题，别写成广告稿。
2. **链接一律 https 绝对 URL。** 禁止相对路径，避免 Agent 解析错站点。
3. **优先区控量。** 优先链接大约控制在 30 条以内；次要材料放进 `## Optional`（或规范里的次级分区），别把整站 sitemap 倒进去。
4. **每条描述短、具体。** 描述控制在约 120 字内：页面是什么、适合回答哪类问题。禁止堆砌关键词，禁止宣称「保证被引用 / 冲排名」。
5. **爬虫规则不进 llms.txt。** GPTBot、OAI-SearchBot、PerplexityBot 的拦/放，只改 robots.txt。
6. **改完用 curl 验收。** 确认 `/llms.txt` 返回 200，Content-Type 合理；再抽测三条列出的链接是否可达。

优先链什么：文档首页、核心产品页、定价、联系/支持、安全与合规说明、更新日志。少链营销落地页堆叠、过期博客、需登录才能看的地址。

## 半天三步落地

**第一步：起草根目录文件**  
在站点根放 `llms.txt`。H1 写清站点名与一句话定位。下列 10–20 条当前最该被 Agent 读的页，每条一行链接 + 一句描述。

**第二步：把爬虫门禁单独改对**  
打开 robots.txt。若要拦训练、放搜索，按 OpenAI / Perplexity 文档分别配置 GPTBot 与搜索用爬虫；不要把这些段落粘进 llms.txt。

**第三步：发布后抽测**  
`curl -I https://你的域名/llms.txt` 看状态码。随机打开三条优先链接。若团队有内部 Agent，让它「只根据 llms.txt 回答本站三个常见问题」，看它会不会指到错误页。

## llms.txt：常见问题

### llms.txt 是什么？放在哪里？

一份给 LLM / Agent 读的 Markdown 索引，通常放在站点根目录 `/llms.txt`，也可以放在 `/docs/llms.txt` 这类子路径，覆盖该目录下的页面。内容是站点说明加优先链接列表，格式见 llmstxt.org。

### 写了 llms.txt，Google 或 ChatGPT 会不会更爱引用我？

不会因此「更爱」。Google Search Central 写明：Google 搜索（含其生成式功能）不使用 llms.txt，写了也不加分不减分。ChatGPT / Perplexity 是否引用，主要仍看爬虫是否放行、页面是否有可抽取的事实文本。llms.txt 最多降低 Agent 找错页的成本，本身不是引用开关。

### GPTBot 要写进 llms.txt 吗？

不要。GPTBot、OAI-SearchBot、PerplexityBot 的允许或禁止，全部写在 `robots.txt`。OpenAI 文档里 GPTBot 用于可能参与基础模型训练的抓取，OAI-SearchBot 用于 ChatGPT 搜索露出，两套规则互相独立；Perplexity 的搜索抓取用 PerplexityBot。llms.txt 只负责在「已经被允许读取」的前提下指路。想拦训练、放搜索，改 robots，别改这份 Markdown 索引。
