费用报销 Agent 驳回报销单时，必须在页面上写清楚依据哪一条报销审核规则、哪张票据或哪个字段超标；员工对驳回结论有异议，直接在报销系统里点申诉，转交指定的人工审核岗做二次审核。谁来接申诉、多久给答复、特批找谁签字，由企业按财务制度预先设定；人工复核后的改判结果同步存底，用来定期修正报销审核规则。

## 驳回通知必须写清哪几项

员工收到一张只写着「审核未通过」的退单通知，不知道该换票、改金额还是补说明，只能反复找财务问。费用报销 Agent 执行驳回动作时，退单卡片上必须同时列出四项信息：命中的报销审核规则编号与原文、触发驳回的具体字段（如单晚住宿费金额、发票抬头、开票日期或消费品类）、系统识别出的票面数值，以及员工下一步可做的操作选项。

如果只是缺附件、选错费用科目或填错金额，员工按提示修改后重新提交即可，不用走申诉通道。只有在员工认为 Agent 识别错了票面信息，或者出差、招待遇到了制度允许的特殊情况时，才点击退单卡片上的「发起申诉」按钮转入人工环节。财务流程里从单据核对到付款放行的关键控制点，见 <NoteLink slug="ap-invoice-agent-payment-control">应付账款 Agent 从对账做到付款，中间哪几道关不能省</NoteLink>。

## 员工申诉找谁审与多久回复

员工点下申诉按钮后，单据不能再回到费用报销 Agent 手里原地打转，系统直接把单据派给人工二次审核队列。接单角色按申诉原因分流：

1. 票据识别类异议：手写发票、境外小票、折叠印章被 Agent 误判为金额不符或假票，分派给财务共享中心的费用会计人工看图核对。
2. 业务特批类异议：展会期间酒店涨价超出日常差旅标准、紧急改签产生的退改费，系统要求员工在申诉栏补填原因并附上业务主管确认记录，再流转给部门负责人与财务主管按企业自己定的金额档签批。

申诉单的响应时限由企业在系统里预设，超时未处理的单据自动提醒财务主管跟进，避免员工垫付资金长期卡在退单状态。

## 人工改判后怎么反哺规则库

人工审核员处理完申诉单，不管维持原驳回还是改判通过，都要在系统里勾选归因标签。财务团队定期把被人工推翻的驳回记录拉出来汇总，通常集中在三类情况：

第一类是解析模板滞后。某地发票版式或行程单改版导致 Agent 抓错金额栏位，这类直接交由技术支持调整票据解析模板。

第二类是报销审核规则写得太死或漏了例外情形。差旅制度里本就有「同行人员合住可合并计算房费标准」的条款，但配进系统的报销审核规则只按单人单日上限拦截；这类由财务制度岗把合住勾选条件补进规则配置里。

第三类是制度本身没说清楚的灰色地带。财务部把高频争议场景整理出来，修订正式的费用管理制度，再同步更新 Agent 的判断逻辑。在扩大 Agent 自动化覆盖范围前先把权限、申诉和审计闭环建好，见 <NoteLink slug="agent-governance-before-scale">AI Agent 安全治理要赶在扩规模之前</NoteLink>。

## 驳回与申诉记录怎么留痕备查

每一张经费用报销 Agent 处理的单据，系统都保留完整的处理记录。记录包含：原始提交的影像件与明细、Agent 初审时间、初审命中的规则版本号、驳回原因原文、员工发起申诉的时间与补充说明、人工二次审核人的工号与改判意见、特批人的签批记录。

内审或外部审计抽查费用合规性时，可以直接按「Agent 驳回后人工改判放行」的条件筛选单据，核查人工推翻机器结论的理由是否充分、特批手续是否齐全，既保留业务上的合理例外，也防止有人借人工申诉通道绕开财务内控。

## 费用报销 Agent：常见问题

### 员工和直属主管都同意报销，能直接跳过费用报销 Agent 的驳回吗？

不能由业务部门单方面跳过。费用报销 Agent 守的是公司统一的财务内控底线；业务主管同意只能说明业务真实发生，超标或票据不合规的报销单走申诉通道后，仍须经过财务审核岗复核，超出设定的阈值的还要按企业权限表由更高层级签批后才能入账付款。

### 同一张报销单里有合规的也有超标的，Agent 是整单驳回还是只退超标项？

由企业的报销系统支持方式决定。支持按明细行拆单的系统，Agent 先放行合规明细进入付款池，只把有问题的那几行拆出来驳回并允许单独申诉；不支持拆单的系统则整单退回，但在退单页面上高亮标出违规明细，员工改好或申诉通过后无需重填其余合规项。

### 报销审核规则谁来维护、改了怎么生效？

报销审核规则由财务部的制度管理岗负责维护，系统管理员配合配置，业务部门无权自行修改。每次调整差旅标准、增删合规票据类型或补充例外条款时，先在测试环境用历史报销单跑一遍模拟审核，核对误拦率和漏拦率；财务负责人确认无误后发布新版本号并记录生效时点。生效之后提交的报销单按新版的报销审核规则审核，生效前的历史单据仍按提交当时的规则版本备查。
