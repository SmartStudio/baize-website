销售预测 Agent 改季度数，交出来的是一份调整建议，不会覆盖销售已提交的数字，也不替销售经理或销售总监落笔改数。总监只认自己确认过的调整数，每次调整都记清楚谁调的、调了多少、理由是什么。现网已有一篇讲 AI 问数问出两个销售额、指标口径信哪个；本篇只讲 Agent 给出了新的季度预测数以后，谁来签认。

## Agent 改的到底是哪个数

企业做管道预测，先按每笔商机所处阶段映射到预测类别。常见分管道、最佳情况、承诺、已成交四类，另有排除在外的一类；阶段跟类别怎么对应、每一类的成交把握比例设多少，企业可以自己改。底层商机归好类后，预测汇总数按预测层级逐级往上滚，每一级指定一位预测经理，负责查看和调整下一级的预测。

预测里的调整只改层级汇总数，不动底下的单笔商机数据；调整结果一直留着，直到有人再次更新。平时有的销售给商机估值习惯偏乐观，有的习惯偏保守，销售经理和总监就用调整把这种偏差算进去；一线销售自己也能用调整，把本期新出现商机的影响先估进去。

销售预测 Agent 算出来的季度改动，就停在调整建议这一层。它只交出一份建议调整数，不覆盖销售已提交的原数，不改底层商机明细，也不替预测经理落笔填调整。

## 建议数要带哪些依据

光报一个改过的季度总数，销售经理和销售总监没法核实。销售预测 Agent 递交建议数时，得把支撑这次调整的商机明细和判断依据一并附上：

- **点明哪几笔商机**：列出这次建议调整对应底下哪几笔单子，方便经理和总监直接点开原单核对。
- **标出阶段或类别变化**：写清这几笔商机近期的所处阶段或预测类别怎么变过，有没有在管道、最佳情况、承诺之间移动。
- **写清滑到下期的理由**：要是判断某笔商机在本期签不下来、会滑到下期，附上做出这条判断的具体依据。

预测经理查看下一级汇总数时，对照这三项依据审阅建议数，还可以针对某笔商机单独给出判断，标明自己信不信这一单本期能成。

## 总监怎么认与谁有权改

商机的阶段、金额、预测类别归商机负责人改，销售预测 Agent 不碰；层级汇总上的正式调整归销售经理和销售总监写，Agent 也不代劳。为什么要赶在扩规模前先把 Agent 的读写边界切开，见 <NoteLink slug="agent-governance-before-scale">AI Agent 安全治理要赶在扩规模之前</NoteLink>。

业务系统可以配置成要求销售每周正式提交一次管道预测，靠提交记录追踪预测期内数字怎么一步步变。销售交完底表、汇总数逐级滚到总监手里后，总监对照 Agent 的建议数和所附依据，按自己的判断敲定调整数。总监认的是他亲手确认后的调整数，确认时记下谁调的、调了多少、理由是什么；碰到拿不准的大单，总监先在单子上记明信不信这一单本期能成，再定汇总数怎么调。

## 几版数字怎么留与季末怎么对

整个预测期跑下来，记录里把销售提交版、Agent 建议版、总监确认版三套数字并排存好，每一版保留各自口径，谁也不覆盖谁：

- **销售提交版**：一线销售每周正式提交、按商机阶段与预测类别逐级汇总上来的管道预测原数。
- **Agent 建议版**：销售预测 Agent 按阶段变动和滑单迹象算出的建议数，连同所附的商机依据一块留存。
- **总监确认版**：销售总监审完下一级汇总与建议依据后，正式确认签认的调整数及调整理由。

这三版数字连同每次调整的操作人、额度和理由，在整个预测期内全量留底。到了季度末，财务和销售团队把销售提交版、Agent 建议版、总监确认版跟实际成交对一遍，看哪一版更接近实际成交结果；上线后怎么拿实际业务结果评估工具表现，见 <NoteLink slug="agent-value-work-finished-metrics">Agent 上线后，效果评估该看哪几个数</NoteLink>。对完总数，再回头复盘当初判断会滑到下期的商机到底成没成，摸清销售估值偏乐观或偏保守的幅度。

## 销售预测 Agent：常见问题

### Agent 觉得某笔商机本期成不了，能直接去改商机阶段吗？

不能。商机的阶段、金额和预测类别只归商机负责人改，Agent 不改底下的商机数据。Agent 判断某笔商机会滑到下期时，做法是给出一个建议调整数，在依据里列明是哪几笔商机、为什么判断某笔会滑到下期，交预测经理标明信不信这一单本期能成，或由商机负责人核实后自己改阶段。

### 预测期内季度数变了好几次，怎么查是怎么变的？

查每周提交记录和各级调整记录。系统可以配置成要求销售每周正式提交一次预测，靠提交记录追踪预测期内数字怎么变；各级预测经理或总监改汇总数时，调整结果在下次更新前一直保留，每笔改动都记着谁调的、调了多少、理由是什么，再配上并排留存的销售提交版、Agent 建议版和总监确认版，随时能核对。

### 管道预测和总监报的数对不上，以哪个为准？

对外上报用销售总监确认后的调整数；底下的管道预测汇总原样保留不动，不为了凑数倒回去改底层商机数据。两边差在哪几笔商机、是因为把销售偏乐观或偏保守的偏差算了进去，还是判断某笔单子会滑到下期，都在调整理由里写清楚，留到季度末跟实际成交对一遍。
