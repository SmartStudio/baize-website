销售预测 Agent 改季度数，本质上是提一次调整建议；它不直接覆盖销售已提交的数，也不替销售经理或销售总监写调整，总监只认自己确认后的调整数，且每次调整都要记下谁调的、调了多少、理由是什么。现网已有一篇讲 AI 问数问出两个销售额、指标口径信哪个；本篇只讲 Agent 改了季度预测数以后，谁来签认。

## Agent 改的到底是哪个数

企业做管道预测时，按每笔商机所处阶段映射到预测类别。常见类别是管道、最佳情况、承诺、已成交，另有排除在外的一类；商机阶段和预测类别怎么对应、每一类的成交把握比例是多少，企业可以自己改。底层商机归好类后，预测汇总按预测层级逐级往上滚。每一级指定一位预测经理，他能查看并调整下一级的预测。

预测里的调整，是直接改层级上的汇总数，不改底下的商机数据；调整会一直保留，直到有人更新它。日常管理里，有的销售给商机估值习惯偏乐观，有的习惯偏保守，销售经理或销售总监用调整把这种偏差算进去；销售也可以用调整估计本期新出现商机的影响。

销售预测 Agent 改季度数，就落在调整这一层。它交出来的是一份调整建议数，不直接覆盖销售已提交的数，不改底层商机数据，也不替预测经理落笔写调整。

## 建议数要带哪些依据

只报一个改过的季度总数，销售经理和销售总监没法核实。销售预测 Agent 出建议数时，要附上明细依据：

- **具体哪几笔商机**：列明这次建议调整对应底下哪几笔商机，方便销售经理和销售总监直接点开核对。
- **阶段或预测类别变化**：标出这几笔商机的所处阶段或预测类别近期是怎么变的，有没有在管道、最佳情况、承诺之间移动。
- **判断滑到下期的理由**：如果觉得某笔商机在本期签不下来、会滑到下期，要写清做出这个判断的具体依据。

预测经理查看下一级汇总数时，对照这些依据审阅建议数，还可以对某一笔商机单独给出判断，标明他信不信这一单本期能成。

## 总监怎么认与谁有权改

商机阶段、金额、预测类别由商机负责人改，销售预测 Agent 不改；Agent 也不替销售经理或销售总监写调整。为什么要在扩规模前先把 Agent 的读写权限切开，见 <NoteLink slug="agent-governance-before-scale">AI Agent 安全治理要赶在扩规模之前</NoteLink>。

企业可以配置成要求销售每周正式提交一次预测，用提交记录追踪预测期内数字怎么变。销售提交后，预测汇总逐级往上滚到销售经理和销售总监手里。总监看完 Agent 的建议数和所附依据后，按自己的判断确认调整数；总监认的是他确认后的调整数，确认时要记下谁调的、调了多少、理由是什么。如果总监对某笔大单拿不准，直接在单据上记下他信不信这一单本期能成，再决定汇总数怎么调。

## 几版数字怎么留与季末怎么对

预测记录里把销售提交版、Agent 建议版、总监确认版并排留着，谁也不覆盖谁：

- **销售提交版**：销售每周正式提交、按商机阶段与预测类别逐级汇总上来的管道预测数字。
- **Agent 建议版**：销售预测 Agent 按商机阶段变化与滑单判断算出的建议数，连同所附的商机依据一起留存。
- **总监确认版**：销售总监审阅下一级预测与建议依据后，亲自确认签认的调整数及调整理由。

这几版数字连同每次调整的人、调整额度和理由，在整个预测期内完整保留。到了季度末，财务与销售团队把销售提交版、Agent 建议版、总监确认版和实际成交对一遍，看哪一版更接近实际成交结果；上线后怎么用实际成交结果评估表现，见 <NoteLink slug="agent-value-work-finished-metrics">Agent 上线后，效果评估该看哪几个数</NoteLink>。季末对完账，再去复盘当时判断会滑到下期的商机到底成没成，以及销售估值偏乐观或偏保守的幅度有多大。

## 销售预测 Agent：常见问题

### Agent 觉得某笔商机本期成不了，能直接去改商机阶段吗？

不能。商机阶段、金额、预测类别由商机负责人改，Agent 不改底下的商机数据。Agent 觉得某笔商机会滑到下期时，做法是给出一个建议调整数，并在依据里列明是哪几笔商机、为什么觉得某笔会滑到下期，交由预测经理对这笔商机给出信不信本期能成的判断，或由商机负责人核实后自己改阶段。

### 预测期内季度数变了好几次，怎么查是怎么变的？

查每周的提交记录和各层级的调整记录。企业可以要求销售每周正式提交一次预测，用提交记录追踪预测期内数字怎么变；每一级预测经理或销售总监改汇总数时，调整会一直保留直到有人更新它，并且每次都记下谁调的、调了多少、理由是什么，销售提交版、Agent 建议版、总监确认版也并排留着，随时能核对。

### 管道预测和总监报的数对不上，以哪个为准？

对外上报用销售总监确认后的调整数；底下的管道预测汇总保留不动，不为了凑数去改底层商机数据。两边差在哪几笔商机、是因为把销售偏乐观或偏保守的偏差算了进去，还是判断某笔商机会滑到下期，都在调整理由里写清楚，留到季度末和实际成交对一遍。
