供应链 Agent 做缺货调拨，只做库存查询、方案计算和送件提醒，创建调拨单这类改系统数据的动作停在审批这一步；主管写定额度内的小量调拨可以配置成在额度内执行，超额度、跨责任单位或数据异常的一律转人签，调出点出库、调入点收货并在下一轮回读确认缺货解除才算办完。现网已有采购 Agent 挑供应商、采购下单金额分级两篇，同批还有一篇讲排产插急单；本篇只讲库存已经在仓里、店里，缺货时怎么调拨。

## 缺货预警后 Agent 先查什么

门店或仓库触发缺货预警后，供应链 Agent 先去业务系统里读取各仓库和门店的库存与动销数据，包括现存、可用、锁定、在途，以及各地的销售速度和设定的安全库存。算方案之前要先核对商品编码：同一个商品在总部系统、门店收银系统、电商后台里的编码可能不一样，数据口径要先统一，否则调拨建议没法算。

底数读齐后，Agent 在不掏空调出点自身安全库存的前提下计算可调拨数量。供应链 Agent 不自己改库存数，也不改企业设定的优化目标。因为仓店之间的缺货调拨往往只能撑几天，Agent 算出调拨数的同时，可以提示计划员和商品负责人同时考虑补货，补货本身另走流程。

## 调拨方案怎么摆给计划员

每一份缺货调拨方案都要把执行要素写全，列明调出点、调入点、数量、预计到达时间，以及这批货调过去以后能撑多久。为了方便计划员和商品负责人比选，Agent 可以一次出几套方案让人选：

- **只从排在前面的几家调**：只选顺位排在前面的几家仓库或门店作为调出点，在不掏空其安全库存的前提下凑数。
- **所有可调的都调**：把全部有富余可用库存、满足调出条件的仓库和门店都算进来，汇总可调拨数量。
- **人自己指定**：计划员不按预设组合走，直接在界面上自己指定从哪家调出、调往哪家以及具体数量。

查询库存和分析方案由 Agent 自己做；到了创建调拨单这类会改业务系统数据的动作，流程停在审批这一步。审批界面上清楚写明要执行的动作和实际参数，由计划员或主管选择允许或拒绝。

## 哪些缺货调拨一定转人签

缺货调拨建议比日常补货建议更敏感，货从哪个仓位或哪家门店挪走，直接牵涉几个仓位负责人和门店店长的业绩考核。常见做法是把调拨建议汇总成每天一张清单，交由区域经理或仓配负责人统一审；特别急的缺货走快速通道，但仍留人工确认环节。主管事先写定额度内的小量调拨，可以配置成由系统在额度内执行；这里的「小量」由主管写成具体的金额或数量。至于当前操作有没有权限执行，由企业自己的业务系统判断，不由 Agent 自己判断。

遇到下面这些情况，缺货调拨一律转人签，Agent 只能送件，不能代签：

- **超过单笔或累计额度**：调拨数量或货值超出了主管事先写定的额度上限。
- **跨责任单位的调拨**：涉及跨法人主体，或者货要从加盟店调出、调入。
- **数据或履约异常**：各系统之间数据互相矛盾、上一批调拨只部分到货、审批超时，或者碰上现有政策没覆盖到的例外。

遇到数据互相矛盾、部分到货或政策空白时，Agent 怎么停下来转人处理，见 <NoteLink slug="agent-stop-conditions-decision-log">Agent 安全护栏：无人值守跑到什么程度该停</NoteLink>。

## 调完怎么算办完与记录怎么留

一笔缺货调拨怎么算办完，有明确的核验标准：调出点完成出库、调入点完成收货，并且在下一轮数据回读时确认调入点的缺货状态已经解除。只出了调拨建议、只过了人工审批、或者只往系统里发了调拨单，都不算办完；为什么先挑这类出库、收货、回读都能当场核验的场景落地，见 <NoteLink slug="ai-verifiable-work-first">AI 落地场景先挑哪类？先看结果能不能当场验证</NoteLink>。如果下一轮回读发现缺货没改善，Agent 就接着出下一套调拨方案，或者带着当时的库存与在途证据转人工处理。

整个过程要在业务系统里完整留痕，记录下当时的建议内容、依据的政策、当时看到的数据版本、是谁批准或改了数字、改数字的理由，以及最终的出入库执行结果。有了这套留痕，团队在月底回看缺货案例时，能清楚分出到底是当时建议算得不准、门店收银或电商后台的数据晚到，还是现场根本没照建议做。

## 供应链 Agent：常见问题

### 总部、门店和电商后台的商品编码不一样，Agent 怎么算调拨？

编码没对齐前不能直接算。同一个商品在总部系统、门店收银系统、电商后台的编码可能不一样，如果直接拉数，现存、可用、锁定和在途就会串号。企业要先建立统一的编码映射口径，Agent 按统一后的口径读取各地库存、销售速度和安全库存，再去算调出点能拨出多少货。

### 审批通过并生成了调拨单，这一单就算结束了吗？

不算。只出了建议、只过了审批、只发了调拨单，都不算办完。要一直跟踪到调出点完成出库、调入点完成收货，并在下一轮回读库存时确认缺货解除，这笔任务才算真正办结；要是回读发现部分到货或缺货没改善，还要出下一套方案或带证据转人工。

### 缺货调拨要从别的门店调货，对方店长不同意怎么办？

涉及门店店长考核或跨责任单位的缺货调拨，按企业的责任分配表转给有权限的区域经理或仓配负责人签批；Agent 只负责送件，在审批单上附上调出点当前的可用库存、预计调出后的剩余库存以及该店自身的安全库存，证明没有掏空对方安全库存。如果对方店长或审批人依然不同意，拒绝的理由和谁改了数字都会记进留痕记录里，由计划员改选其他调出方案。
