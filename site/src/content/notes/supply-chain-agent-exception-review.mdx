供应链 Agent 处理缺货调拨，只做库存查询、方案测算和送审提醒，创建调拨单这类改系统数据的动作停在审批界面等人工拍板。主管事先写定额度的小量调拨，可以配置成在额度内执行；超额度、跨责任单位或数据异常的单子一律转人签，直到调出点出库、调入点收货且下一轮回读确认缺货解除才算办完。现网已有采购 Agent 挑供应商、采购下单金额分级两篇，同批还有一篇讲排产插急单；本篇只讲库存已经在仓里和店里，缺货时怎么调拨。

## 缺货预警后 Agent 先查什么

门店或仓库触发缺货预警后，供应链 Agent 先去业务系统读取各仓各店的库存与动销底数，把现存、可用、锁定、在途四类库存连同各地销售速度、安全库存一并拉出来。动手算方案前先核对商品编码：同一款商品在总部系统、门店收银系统和电商后台里的编码可能不一样，数据口径没统一前没法算调拨。

底数读齐后，Agent 在不掏空调出点自身安全库存的前提下测算可调数量。供应链 Agent 只读数算账，不自己改库存数，也不改企业定好的优化目标。仓店之间的缺货调拨往往只能撑几天，Agent 给调拨数的同时可以配置成顺带提醒计划员和商品负责人评估补货，补货本身另走流程。

## 调拨方案怎么摆给计划员

递给计划员的缺货调拨方案要把执行要素写全，列清调出点、调入点、调拨数量、预计到达时间，以及这批货调过去以后能撑多久。方便计划员和商品负责人比选，系统可以配置成一次给出几套方案让人挑：

- **只从排在前面的几家调**：挑顺位靠前的几家仓库或门店当调出点，守住各自安全库存的前提下凑够数量。
- **所有可调的都调**：把全部有富余可用库存、符合调出条件的仓库和门店都拉进来汇总可调量。
- **计划员自己指定**：不套预设组合，计划员直接在界面上点选从哪家调出、调往哪家并填具体数量。

查库存和比选方案由 Agent 自己跑完；一到创建调拨单这类会改业务系统数据的动作，流程就停在审批这一步。审批界面写明要执行的动作和实际参数，由计划员或主管选择允许或拒绝。

## 哪些缺货调拨一定转人签

缺货调拨建议比日常补货建议敏感得多，货从哪个仓位或哪家门店抽走，直接牵涉几位仓配负责人和门店店长的业绩考核。常见做法是把调拨建议拢成每天一张清单，交区域经理或仓配负责人统一审；特别急的缺货走快速通道，照样保留人工确认。主管事先写明额度的小量调拨，可以配置成由系统在额度内放行，具体多少金额或数量算小量由主管定清。当前操作有没有权限落地，归企业自己的业务系统校验，不由 Agent 自己判断。

碰上下面三类情形，缺货调拨一律转人签，Agent 只负责送件，不能代签：

- **超过单笔或累计额度**：调拨数量或货值越过了主管事先写定的额度上限。
- **跨责任单位的调拨**：牵涉跨法人主体，或者货要进出加盟门店。
- **数据或履约异常**：各系统之间数据互相矛盾、上一批调拨只部分到货、审批超时，或者撞上现行政策没覆盖到的例外。

遇到数据互相矛盾、部分到货或政策空白时怎么让流程停下来转人处理，见 <NoteLink slug="agent-stop-conditions-decision-log">Agent 安全护栏：无人值守跑到什么程度该停</NoteLink>。

## 调完怎么算办完与记录怎么留

一笔缺货调拨算不算办完，看三条核验结果：调出点完成出库、调入点完成收货，并且在下一轮回读数据时确认调入点缺货状态已经解除。只出了调拨建议、只过了人工审批，或者只往系统里发了调拨单，都不算办完；为什么落地先挑这种出库、收货、回读都能当场核实的场景，见 <NoteLink slug="ai-verifiable-work-first">AI 落地场景先挑哪类？先看结果能不能当场验证</NoteLink>。要是下一轮回读发现缺货没改善，Agent 就接着出下一套方案，或者带上当时的库存和在途证据转人工处理。

全过程要在业务系统里留底，记清当时的建议内容、依据的政策、读取的数据版本、是谁批准或改了数字、改数理由以及最终出入库结果。月底回看缺货案例时，翻开记录就能分清是当初建议算偏了、门店收银与电商后台数据晚到，还是现场没照批好的方案执行。

## 供应链 Agent：常见问题

### 总部、门店和电商后台的商品编码不一样，Agent 怎么算调拨？

编码没对齐前不能直接算。同一款商品在总部系统、门店收银系统和电商后台里的编码可能各异，直接拉数会把现存、可用、锁定和在途库存串乱。企业要先建好统一的编码映射口径，Agent 按统一口径读取各地库存、销售速度和安全库存，再去算调出点能拨出多少货。

### 审批通过并生成了调拨单，这一单就算结束了吗？

不算。只出了建议、只过了审批、只发了调拨单都只是中间步骤。要一直跟踪到调出点完成出库、调入点完成收货，并在下一轮回读库存时确认缺货已经解除，这笔调拨才算办结；要是回读发现部分到货或缺货没缓解，还要出下一套方案或带证据转人工。

### 缺货调拨要从别的门店调货，对方店长不同意怎么办？

牵涉门店店长考核或跨责任单位的缺货调拨，按企业的责任分配表转给有权限的区域经理或仓配负责人签批。Agent 只管送件，在审批单上附上调出方当前的可用库存、调走后的剩余库存以及该店自身的安全库存，证实调走后不低于对方安全库存。对方店长或审批人还是不同意的，拒绝理由和谁改了数字都记进记录里，由计划员改选其他调出方案。
