应收催款 Agent 催到第几次转给销售，按企业自己定的账龄档位和触达次数上限执行。开催前先筛掉我方单据未齐和存在履约争议的账款；刚逾期时由 Agent 起草对账函与催款函、经应收会计确认后发出；一旦到了企业定的账龄档、发满设定次数仍无回应、客户提出争议或要求减免延期、承诺付款却没兑现，或者对方本身是重点客户，就立即转给销售跟进，Agent 同步打包账龄、往来记录和承诺台账。

## 开催之前先筛掉哪些单

单纯按账龄分档对做财务报表有用，直接拿来派发催收任务却不够。同样挂在逾期账龄表上的款项，有的是客户内部付款审批流走得慢，有的是客户故意拖延，还有的是我方交付根本没完成、客户拒付有理。在把账单放进催收队列之前，先要判断这笔款该不该催。

应收催款 Agent 第一步先排查内部阻塞项：核查项目的验收单客户签字了没有、对应发票开出了没有、客户那边签收了没有。只要验收单或发票还卡在我方手里没完成，这笔应收款就不进对外催收队列，直接转入内部待办清单督促相关责任人补齐手续。

第二步筛查履约争议。如果客户已经提出质量投诉、反映到货数量短少，或者对账函上的金额迟迟没确认，这类账款先转走争议处理流程，由业务和售后团队核实情况，不套用常规催收话术去催客户打款。

## 前几轮催收能做什么与不能做什么

筛掉内部阻塞和争议单后，常规应收款按分层思路推进。账款到期前，应收催款 Agent 先发出到期提醒，请客户确认单据齐全并启动内部付款流程；刚进入逾期第一档时，Agent 根据合同与发票明细起草对账函和催款函草稿，交由应收会计核对确认后再发给客户。对外发信前哪几步要留人工审批，见 <NoteLink slug="crm-outbound-agent-send-approval">CRM 外联 Agent 发信前，哪几步要留人工审批</NoteLink>。为了避免高频打扰客户，系统可以给每个客户设每天的发送上限。

每次跟客户沟通后，应收催款 Agent 在台账里逐项登记：客户给出的承诺付款日期、承诺金额、对应的发票号、对方承诺人姓名、确认方式，以及上一次承诺是否按期兑现。结合客户过去的回款习惯和历次承诺兑现情况，财务能看出对方是流程慢还是习惯性拖欠。

Agent 的操作边界与话术边界要在系统里定死。它不能替人决定费用减免、付款延期或暂停供货，不直接向客户发送未经人工确认的书面文件，也不修改财务凭证或直接入账；在起草的任何文字里，不承诺减免金额、不未经审批答应延期，更不在书面文件里擅自承认我方存在质量问题。

## 哪些信号一出现就转给销售

催款函发满企业定的次数后客户依然没有任何回应，或者逾期天数跨入企业定的下一档账龄，应收催款 Agent 就停止常规提醒，把工单转交给负责该客户的销售人员。如果逾期账款对应的客户本身属于重点客户，关系维护敏感，系统可以配置成一进入逾期就直接转交销售出面沟通。

客户在沟通中临时提出质量或数量争议、要求减免尾款或申请延长账期，同样立即停止自动催收并转交销售处理；电话或消息沟通里遇到哪些信号要转真人接手，见 <NoteLink slug="voice-sales-agent-human-handoff">语音销售 Agent 给客户打电话，聊到哪一步要转真人</NoteLink>。此外，要是客户此前给出了明确的付款日期和金额，到期却没打款，甚至连续承诺不兑现，说明常规提醒已经无效，下一步该由销售出面同客户直接谈具体的回款保障措施。

## 转交时交什么与后面谁接手

转交销售时，应收催款 Agent 把这笔款项的账龄分布、对应合同与发票号、前期往来催收记录、客户历次承诺日期与未兑现记录打包成一份交接卡推给销售。当逾期进入更深一档时，升级为销售负责人与财务负责人两条线联动跟进，向客户要书面付款承诺，必要时由管理层拍板暂停后续发货。在这个阶段，对外沟通全部由人来做，Agent 只在后台准备资料和更新台账。

如果销售和财务两条线介入后客户依然拒不付款，账款进入法务催收或诉讼流程。此时应收催款 Agent 按时间线把整套证据包整理齐全，涵盖合同原件、签字验收单、发票及送达凭证、对账确认函以及历次催收沟通与承诺记录，成套移交法务团队接手。

## 应收催款 Agent：常见问题

### 发票还没寄到客户手里，到了账期会自动发催款信吗？

不会。开催前要先排除内部阻塞。如果查到验收单还没签回，或者发票对方还没收到，这笔账款不进对外催收队列，直接转进内部待办事项提醒我方经办人先补齐单据，责任在我方时不去催客户。

### 客户在回复里说货有质量问题要求少付钱，Agent 怎么回？

Agent 不直接回复，更不在书面文件里承认我方质量问题或答应减免。一旦识别到客户提出质量投诉、数量短少或要求减免延期，系统立即将该笔账款从常规催收队列里撤出，转入争议处理流程并通知销售与售后人员接手核实。

### 账龄到哪一档，Agent 就不再自己发催款函？

各档账龄的具体天数由企业根据行业回款周期自己设定。刚逾期的初级账龄档，由应收催款 Agent 起草催款函和对账函并经人工确认后发送；一旦逾期跨入企业设定的升级账龄档，就升级到销售负责人和财务两条线由人工出面沟通、索要书面付款承诺或评估暂停发货，Agent 不再发常规催款函，只负责整理历史资料和更新台账。
