采购 Agent 替企业挑供应商短名单，入选与落选理由要写明事实依据、比对指标与有效期限。只给一个评分或者几句模糊评语，采购员没法核实，审计事后也没法查账。短名单是采购决策的参考输入，最终由采购员复核、审批人签字确认，下单与付款都由人来经办。理由写得越实在，人工复核越省心。

## 读需求和约束：理清零件规格与交付要求

程序先从采购系统调取待采物料清单。对于结构化字段，系统抓取零件材质、公差范围、环保标准与送达地点。对于申请单里的文字备注，系统抓取特殊包装、现场技术服务或指定质保期等非结构化要求。在管理系统权限与任务边界时，建议参考 <NoteLink slug="agent-governance-before-scale">AI Agent 安全治理要赶在扩规模之前</NoteLink>。

需求部门对物料参数与交期负责，采购员确认预算范围与采购方式。物料参数如果缺项或者技术要求相互冲突，系统在屏幕上标出缺失位置，采购员找业务部门沟通补齐，再让系统重新解析。

## 查合格库与资质：核对经营范围和证照状态

系统调出合格供应商底表做初选。程序核对候选企业的经营范围、质量认证编号、行业准入许可与有效期限，同时查验工商存续状态与涉诉记录。证照过期、经营异常或超范围经营的供应商，系统直接标为不合格，并写下失效的证件名称与到期节点。

资质审核专员定期维护准入标准，品类采购员核对业务范围。供应商如果拿的是换证阶段的政府公函，这类非标凭据交由审核专员人工判定。专员在后台点击通过并上传凭据，系统才把该企业纳入候选比对。

## 比对履约历史：拉出交期良率与质量记录

系统从进销存和质量系统调取过往记录，比对同类零件的历史供货情况。系统列出送货延期次数、来料检验不良率、退货批次与技术服务响应表现。要是新引进的供应商没有供货记录，系统如实标注历史数据为空，单独列出样品送检合格报告编号与试制评分。

质量工程师判定历史质量异议归属，避免把产线调试问题算成供应商缺陷。采购专员根据物料对交期的敏感程度，在后台设置比重权重。系统比对完成后列出指标明细表，留给下一步综合评估。

## 出短名单与理由：入选和淘汰分别写清事实

系统排出候选供应商推荐顺序，给每家企业生成结构化说明。比如某家入选，理由写明合格率达标、持有对应认证、历史交付按期履约，而且车间运输距离短；某家落选，理由写明环保认证过期，或者近期供货有整改未结案记录。系统不写含糊的主观评价，每条理由都要对应具体工单、报告编号或数据字段。

AI 完成文本输出后，把短名单报告与底层支撑数据打包锁定，禁止算法擅自改动。在采购全流程控制与付款风险把关方面，具体交接规范见 <NoteLink slug="ap-invoice-agent-payment-control">应付账款 Agent 从对账做到付款，中间哪几道关不能省</NoteLink>。

## 采购员复核签字：人工改动留痕并逐级审批

采购员打开推荐界面，抽检候选供应商的资质附件、过往交期明细与推荐依据。采购员如果判定某家落选供应商近期已做完技术改造、质量隐患已经排除，可以手动移入短名单，但必须在系统里录入调整理由并上传整改报告。系统记录采购员账号、操作节点与补充凭证，和原始推荐并排保存。

复核完成后，采购员发起系统审批。采购主管与财务审批人核对调整记录与推荐理由，由人在系统内电子签字。后续询价比价、签署合同、下达订单与付款申请，都由人按既定流程办理。

## 采购 Agent：常见问题

### 采购 Agent 生成的短名单理由如果写得太简略，会给内审带来哪些隐患？

理由写得太粗会导致事后没法查账。系统如果只给一个综合评分或标签，内审人员抽查时根本看不出入选供应商是否真的符合各项资质，也猜不出落选企业是不是因为突发特殊情况偶发延期。缺乏事实支撑的评分容易掩盖主观倾向或算法偏向，带来合规审计风险。推荐依据应细化到具体的检验报告编号、证书有效截止日期与不良品批次记录。

### 采购员在系统里推翻采购 Agent 的推荐排序时，需要保留哪些记录？

采购员改动短名单时，系统要留存修改前后的对比版本和修改凭证。系统应当记录修改人的账号、操作时间节点、变动的名单，以及采购员手写的调整理由。比如采购员把排在后面的供应商提到前面，需要上传管理层特批邮件、战略合作协议或产线应急保供申请单。留下完整的修改轨迹，后面做内审时能讲清决策依据，防范采购合规风险。

### 企业引入采购 Agent 之后，新供应商入库时的供应商准入规则由谁来维护？

供应商准入规则由采购管理部门和质量委员会来定。采购 Agent 只是按规则执行筛选的工具，自己没有定规则或改标准的权限。企业应当由合规部门、品类采购专家和法务人员共同定好准入条件，包括证件资质、验厂打分线与环保指标。新规则经管理层审批后配进系统。系统管理员定期校准规则参数，采购 Agent 照着最新标准筛查，把好入库门槛。
