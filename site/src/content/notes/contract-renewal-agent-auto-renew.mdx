合同续约 Agent 扫出带有自动续约条款的合同时，不能放任合同到期默认顺延，必须在合同约定的最晚通知窗口前把它拦下来，交由使用部门和合同负责人拍板。Agent 负责提取合同到期日、自动续约条款和提前通知期，按通知截止日倒推发出多轮提醒；内部确认是原价顺延、重谈条件还是到期终止后，所有对外发出的不续约通知函或补充协议，都必须经人工审核确认后再发出。

## 到期日与提前通知期怎么读与提醒怎么倒推

企业签下的软件订阅、设备维保、场地租赁和常年服务合同里，经常包含自动续约条款。如果只按合同本体的到期日设提醒，等提前几天收到弹窗时，往往已经错过了合同规定的「到期前书面提出不续约」的最晚通知窗口，企业只能被动再绑一个周期。

合同续约 Agent 在合同归档入库时，先从正文和补充协议里提取四个关键字段：合同终止日、是否包含自动续约条款、不续约的最晚提前通知期，以及自动顺延后的周期长度与调价规则。接着，Agent 以「合同终止日减去提前通知期」算出内部决策截止日，再从截止日往前留出内部评估与谈判缓冲期，分轮次向合同管理员、预算归口部门和实际使用部门推送待办提醒。要是到了截止日前仍无人响应，系统自动把提醒升级推给部门负责人，确保每一份带自动续约条款的合同都在窗口关闭前有人处理。

## 续不续与要不要重谈价格由谁来确认

收到合同续约 Agent 的预警卡片后，合同不能因为没人提异议就默认过关，系统会在工作台里强制挂起一道内部确认流，要求使用部门与采购或法务负责人显式勾选处置意见。内部调用接口和审批流哪些能放行、哪些要拦下等人工确认，见 <NoteLink slug="agent-tool-call-auto-approval-rules">Agent 工具调用自动审批：哪些放行、哪些拦下</NoteLink>。

使用部门先填评估：如软件活跃账号与采购席位差额、维保响应是否达标、下年业务量是否缩减。采购或合同负责人结合行情评估：继续使用且原条款合理的，勾选按原条款顺延；使用量下降、同类服务降价或顺延会自动涨价的，勾选「需重新议价」，在窗口期前发起重谈；业务停用或换供应商的，勾选「到期不续约」，转入解约通知流程。

## 不续约通知怎么起草与对外函件谁来发

一旦拍板到期不续约，或先发函阻断顺延再谈新合同，动作必须赶在最晚通知日前完成。合同续约 Agent 根据原合同送达条款，核对对方收件邮箱、地址和生效方式，引用原合同编号及自动续约条款条文，起草《到期不续约通知函》草稿。

草稿只保存在内部审批台，合同续约 Agent 不直接外发邮件，也不自动盖章。法务与合同负责人核对合同名称、解除依据和交接事项，确认无误后由人工发送邮件或寄送纸质函件；关于 Agent 读信与对外发信的权限边界，见 <NoteLink slug="agent-read-mail-vs-calendar-send">AI Agent 权限：读邮件行，发信要先批吗</NoteLink>。合同要求快递或签字盖章送达的，系统生成线下寄送待办单，督促经办人上传快递底单与签收凭证。

## 续约决策记录怎么留存与怎么防漏拦

每一份合同从触发提醒到最终办结，合同续约 Agent 都在合同台账里留存完整记录，包括提取的条款原文截图、历次提醒推送时间与接收人、使用部门评估意见、采购与法务审批结论、最终处置方式，以及对外发出的不续约通知函副本、邮件回执或快递签收单。

为了防止因扫描件模糊或条款表述生僻导致漏拦，经办人在新合同入库时要人工确认一次 Agent 抓出的到期日和提前通知期；一旦复盘发现某类补充协议或外文合同里的自动顺延表述曾被漏读，团队立即把对应句式补进提取规则库，并重跑存量合同扫描。

## 合同续约 Agent：常见问题

### 合同没写自动续约，到期前也要 Agent 拦下来审批吗？

没有自动续约条款的合同到期后自然终止，不会产生被动锁定期款的法律风险，但同样需要合同续约 Agent 提前提醒，防止核心业务断档：比如生产软件授权、厂房租赁或关键原材料框架协议如果到期忘了续签，会导致系统停服或供应中断。Agent 按续签谈判所需的周期提前提醒使用部门评估是否启动新合同签署流程。

### 发现时已经过了不续约的最晚通知期，怎么补救？

合同续约 Agent 检测到当前日期已越过最晚通知窗口、但合同尚未进入下一周期时，立即标红并升级推送给法务与采购主管。经办人先核查对方在履约期内是否存在违约、服务未达标或未履行前置告知义务等可主张解除的事由；若对方履约无瑕疵，则由采购或业务负责人出面协商，争取通过补充协议缩短顺延周期、核减席位或支付小额违约金提前解约。

### 自动续约条款里最容易漏看什么？

审查自动续约条款时最容易漏看三处细节：第一是提前通知期的计算口径，有的按自然日算，有的按工作日算，还有的限定必须在特定月份内提出；第二是有效通知的送达方式，不少合同要求寄送加盖公章的书面函件到指定地址，单发普通邮件可能不被认可；第三是顺延后的价格联动条款，部分合同约定自动续约后按目录价结算或自动上浮比例，不拦下来重谈就会拉高成本。
