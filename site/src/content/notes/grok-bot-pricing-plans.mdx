## 哪几档套餐包含 Grok Bot

根据 [x.ai 价格页](https://x.ai/pricing)，方案分 Free、Plus、Premium、Super、Ultra 五档，Grok Bot 从 Premium 档列入。标明价格不含税费，在 Cursor 内调第三方模型另计费，价格可能调整。还不清楚 Grok Bot 用途的读者，先看 <NoteLink slug="grok-bot-persistent-ai-teammates">Grok Bot 是什么？AI Agent 云端同事的实战指南</NoteLink>。

在 The X Subscription 上，个人和团队座位的 Premium、Super、Ultra 都含 Grok Bot。Plus 和 Free 不含，需升级到 Premium 或以上。选 X Subscription 套餐时，先看这一档含不含 Bot。

官方推荐初用 AI 选 Premium，每天用 Agent 选 Super，重度用户选 Ultra；Plus 适合 AI 用得少的社交创作者，协作团队选 Teams，大组织看 Enterprise。订阅由 X Subscription Corp 官方直销，不授权第三方，从别处买来的订阅可能被停用。

## 额度池按周怎么共用和刷新

根据 [x.ai 价格页](https://x.ai/pricing)，每档配有一个 AI 用量池，在 Grok 和 Cursor 间共用。在 Grok 里该池覆盖 Chat、Imagine、Voice 和 Bot，档位越高池越大，不同产品消耗不同。同一个 X Subscription 套餐下，Grok 和 Cursor 的用量从同一个额度池里扣。

根据 [Cursor 套餐与计费文档](https://cursor.com/help/grok-bot/plans)，Grok Bot 没有单独计量，与 Cursor 和 Grok 从同一个每周池扣除。Super 和 Ultra 的每周池比 Premium 档更大。额度按周刷新，剩余用量在设置或 `grok.com/dashboard` 的 `Usage` 看，用完等刷新或充值。

## 用完后怎么充值与设置封顶

根据 [Cursor 套餐与计费文档](https://cursor.com/help/grok-bot/plans)，每周池用完后，额外用量从预付额度扣。可以买额度，也可以开 Auto Top-up。

想控制开销，可在 `grok.com/dashboard/billing` 的 `Additional usage credits` 下设每月额外用量上限。想在用完后不再产生费用，不开 Auto Top-up 或设好上限即可，见 [Cursor 常见问题解答](https://cursor.com/help/grok-bot/faqs)。

根据 [Cursor 套餐与计费文档](https://cursor.com/help/grok-bot/plans)，Grok Bot 试用是一笔用量额度，另有七天期限，按 Agent 的步骤和 token 扣，不按消息条数；一个大任务可能一次用完，用掉的额度不退不补。

按周刷新加充值的用量要和年度预算放在一起算。参考 <NoteLink slug="ai-usage-pricing-budget">AI 按量计费后，企业一年一编的预算还管得住吗？</NoteLink> 算清预算。

## 老计划与 SuperGrok 怎么算

根据 [Cursor 套餐与计费文档](https://cursor.com/help/grok-bot/plans)，老计划里 Pro、Pro+、Ultra 和 Cursor Teams 含 Grok Bot，每周用量 Ultra 最高、Pro+ 次之、Pro 再次。老账号可关联个人 SuperGrok、SuperGrok Plus、SuperGrok Heavy 或 X Premium+ 换用量，SuperGrok Lite 不含。

关联属于用量授权，不是 Cursor 计划，不能解绑挪号。两边用量不叠加，取每周用量更多的一方。使用 The X Subscription 的用户不需关联。

根据 [Cursor 手机指南](https://cursor.com/help/grok-bot/mobile)，账号已经包含 Grok Bot 的，用同一个 Cursor 账号登录手机就行，不要在应用商店买第二份订阅。

## Grok Bot 价格：常见问题

### Plus 能不能用 Grok Bot？

Plus 档不能使用 Grok Bot。根据 Cursor 套餐与计费文档，Plus 和 Free 不含 Bot 权限，需升级到 Premium、Super 或 Ultra 档位。

### 试用额度一个任务用完了能不能补？

试用额度用完后不能补发。试用是一笔用量额度，另有七天期限；用掉的不退不补；要继续用就升级到 Premium、Super 或 Ultra。

### 团队买 X Subscription 套餐，每个人都能用 Grok Bot 吗？

团队购买 The X Subscription 套餐，每个付费座位（Premium、Super、Ultra）都包含 Grok Bot，用量从该座位每周池里扣。大组织要发票、共享用量池或高级安全的看 Enterprise。
