面试安排遇到面试官临时有事需要改时间，可以交给 Agent 去找空档、拟通知，发给候选人的那封通知由人事确认后再发。工具自动发的邮件只写时间变了，改期原因、致歉和新的备选时间段要由人事补齐；同一位候选人被改期多次的，改由人事直接打电话沟通；面试官日程、会议室、视频会议链接和候选人通知一起更新，改期原因、操作人、通知时间和候选人确认结果都留在候选人档案里。

## 谁能改面试安排

日常约面时，有的办公协作工具在帮助中心里写了日历的一对一预约功能，可以用来预约候选人面试时间；官网文章也介绍了把招聘系统和日历集成的做法，由招聘系统锁定面试官空闲时间并同时询问应聘者，把双方时间协调一致后，在面试官日历里创建面试日程、给面试官推送消息卡片，并在招聘系统里通过邮件或短信给应聘者发送面试通知。初次约面按这套流程跑，人事不用逐一核对每封确认信；前端筛选环节哪些交给人看，见 <NoteLink slug="ai-resume-screening-human-review">招聘 Agent 筛掉的简历，要不要再让人看一遍？</NoteLink>。

到了改期环节，处理方式和初次约面不同。面试官临时出差、被拉进紧急会议或者家里有事，在日历或招聘系统里提出改期后，Agent 先接手去查这位面试官接下来几天的空闲时段，同时核对同场其他面试官和旁听人员的日历，挑出几组各方都能出席的备选时间，算好新的面试排期方案推给负责该岗位的人事专员。Agent 只管找空档和起草方案，不能直接把改期指令发给候选人。

## 改了以后先通知谁与通知写什么

有的日历工具支持组织者在日历里点重新安排来重新预约时间，预约成功后系统会向预约者发送邮件，组织者日程也会同步更新；取消预约时组织者填写取消原因，系统会给预约者发取消邮件。这类工具自带的通知邮件通常只写明时间发生了变更或预约已取消，不会把来龙去脉讲清楚。如果直接让工具把这种模板邮件发给候选人，候选人只看到时间被改，不知道为什么改，也不知道能不能换别的时段。

因此至少改期这一类通知要由人过目。Agent 在后台起草好发给候选人的改期邮件或短信草稿，人事专员打开草稿，把改期的具体原因、必要的致歉以及供候选人挑选的几个新时间段补进去，检查语气妥当后再点发送。一旦候选人选定了新时间，面试官的日历日程、线下会议室预订、线上视频会议链接以及发给候选人的正式确认函要一起改过来，漏改其中任何一个，面试当天都会出现人找不到房间或进错会议室的状况。排期变动时人工能改多少、怎么守住边界，见 <NoteLink slug="store-scheduling-agent-manager-edits">门店排班 Agent 排出班表，店长能改多少？</NoteLink>。

## 候选人没回复怎么办

改期通知发出去以后，Agent 可以配置成按企业定的时间盯着候选人的回复状态。如果候选人在日历链接里点选了新时段，或者回了邮件确认，Agent 就把新时间写进招聘系统和面试官日历，把原来的旧会议室退掉、换订新时段的房间。

如果过了设定的等待时间候选人还没动静，Agent 就给人事专员发一条提醒，由人事换用短信或电话去联系，问清楚是没看到邮件还是新给的几个时段都不方便。另外，改期次数多了也要有人盯着。系统里可以设一条规则，只要同一位候选人在一轮面试里被内部原因改期多次，就不再只发改期邮件，转交人事专员先打电话向候选人解释清楚、当面敲定新时间，再回系统里补走改期流程。

## 面试排期改动怎么留记录

每一次面试排期发生变动，不管是面试官临时改期、人事手动调表，还是候选人主动申请换时间，都要在招聘系统的候选人档案里留存完整记录。记录里写清楚四件事：

- **发起人与操作人**：是谁提出的改期申请，是面试官本人、用人部门主管还是候选人，最后由哪位人事专员确认下发。
- **改期原因**：具体是因为业务会议冲突、出差变动、面试官生病，还是候选人临时有事，照实记下，不留空白。
- **原定与新定时间**：原定的面试日期和时段、改期通知发出的具体时间、新敲定的面试时段，以及会议室和视频链接是否已同步更新。
- **候选人确认状态**：候选人是通过链接自助确认、回复邮件确认，还是由人事电话沟通后代为确认，附上对应的沟通截图或纪要。

招聘负责人定期把候选人档案里的改期记录拉出来看，查出哪些部门或面试官经常临时改期，拿记录去跟用人部门对齐纪律，减少候选人因反复改期而放弃面试。

## 面试安排：常见问题

### 面试安排改了，候选人没回复怎么办？

改期通知发出后，若在设定的等待时间内没收到候选人的邮件回复或链接选定结果，Agent 提醒人事专员跟进。人事改用电话或短信联系候选人核实；若备选时段都不方便，由人事在电话里问清候选人有空的日子，再让 Agent 重新匹配面试官空档。

### 候选人自己要改时间，走哪条路？

候选人如果临时有事需要调整时间，可以通过预约邮件里的改期入口提交申请，或者直接联系人事专员。Agent 收到申请后，同样去检索面试官日历里的其他空闲时段，生成新的备选方案交给人事确认；人事核对无误后更新日程、会议室和视频链接，并向面试官推送时间变更提醒卡片，原定的旧时段随之释放。

### 面试排期冲突了，Agent 能自己挑一个新时间吗？

面试排期出现冲突时，Agent 可以自己去查面试官日历和会议室空档，挑出几个双方都不冲突的候选新时间，但不能自己决定新时间并直接发给候选人。最终发给候选人的备选时间段、改期说明和致歉措辞，都要由人事专员确认后再发出，避免工具自动挑出的时段不符合业务部门的安排。
