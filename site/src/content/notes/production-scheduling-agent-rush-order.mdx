排产 Agent 接到急单插单请求后，先冻结当前排程基线，在排程副本里把急单放进当前订单池一起重算，正式生产计划保持不动。重算后按保交期、紧凑产出、最小扰动、少换型几种取向生成多套备选方案，标清受影响订单清单、换型次数和延期天数。车间主任会同计划员、销售、采购共同确认选哪套方案，评审通过前车间按原计划执行。

## 急单进来先算什么

一张急单能不能接，不能只算这张单自己最早哪天做完。急单占用的机台时间、物料和队列位置都来自同一张生产计划，排产 Agent 处理急单插单时，先把当前正在执行的排程冻结为基线，再拉出一个排程副本，把急单和当前所有在手订单放在一起重算。在审批完结之前，车间线上跑的正式计划不做改动。

在排程副本里重算完后，排产 Agent 把副本结果和基线逐单对比，核查每一张在手订单的计划开始日、完工日、占用资源、加工顺序、缺料情况、换型次数和延期天数，生成一份受影响订单清单。哪些原本按期交付的订单被挤到了后面、哪几台设备增加了换型、哪几批物料跟不上新排期，都在清单里逐条列明。排产模拟之所以适合交给工具先算，是因为延期天数和换型次数都能直接在排程表上核验，挑选这类场景的思路见 <NoteLink slug="ai-verifiable-work-first">AI 落地场景先挑哪类？先看结果能不能当场验证</NoteLink>。

排程系统可以配置成对已下发任务加锁，同时给在手订单设置保护等级。已经下发到车间的生产任务默认锁住，急单插单先在锁定范围之外寻找机台空档。大客户订单一旦延期可能触发合同罚则，企业可以把这类订单设为高保护等级，排产 Agent 在副本里做模拟排程时不会强制推迟高保护等级订单的交期。

## 几套方案怎么摆给车间主任

在现有产能里塞进一张急单，是在急单交期、已承诺订单交期、换型次数和整体产出几件事之间做取舍，几项指标互相牵制。排产 Agent 可以配置成按不同取向各算出一套备选方案，把每套方案的代价列在同一张对比表里交给人选。

常见的几套方案各有侧重。保交期方案让急单和其他订单尽量不误交期，代价是挤动的订单可能较多，换型可能增加；少换型方案把同模具的活排在一起，急单可能要等当前批次做完；最小扰动方案让已排好的计划尽量不动，急单完工可能偏晚；紧凑产出方案把机台排满、整批尽早完工，个别订单的交期可能靠后。

每套方案呈给车间主任和计划员时，附上对应的受影响订单清单、换型次数、延期天数、缺料风险以及是否需要加班或外协。排产 Agent 只把账算清并排摆出来，不替人做选择。

## 车间主任批什么与谁一起会签

从备选方案里选哪套落地属于经营判断：让哪张原有订单晚交、要不要加班外协、要不要和客户重谈交期，都由人拍板。方案下发前，由车间主任、计划员、销售和采购各自确认。

车间主任核对产线换型频次、班组工时负荷与加班可行性；计划员核对产能平衡与锁定任务变动；采购核对物料到货日期能不能接上；销售核对受影响订单的客户沟通空间。排程表上的日期变化只代表计划结果变了，客户交期改不改要由有权承诺的人确认。

评审要设回复时限，超时怎么处理事先约定。在四方评审通过前，车间正在执行的计划保持不变。

## 什么情况停下转人与记录怎么留

排产方案算得准不准，取决于底层基础数据准不准。如果系统里的标准工时、设备换型时间或采购物料到货日期本身有偏差，排产 Agent 算出来的完工日和延期代价也会跟着失真。遇到车间从没做过的新产品组合、缺少历史工时与换型数据，或者每套模拟方案都会让高保护等级订单延期时，排产 Agent 给不出可靠方案，就要停下计算并转交计划员和车间主任人工排定。关于无人值守流程跑到哪一步该停下转人，见 <NoteLink slug="agent-stop-conditions-decision-log">Agent 安全护栏：无人值守跑到什么程度该停</NoteLink>。

每一次急单插单从发起到落地的全过程都要在系统里留痕。记录内容包括：插进来的是哪张急单、当时冻结的排程基线是什么、排产 Agent 出了哪几套方案、每套方案各自的换型次数与延期代价、四方会签时选了哪一套、由谁在什么时间批准下发。后续如果出现订单延误或车间工时异常，团队直接调出当次评审记录核对当时的决策依据。

## 排产 Agent：常见问题

### 大客户订单怕延期罚钱，排程时怎么保？

企业可以在系统里给订单设置保护等级。对于延期可能触发合同罚则的大客户订单，计划员将其标为高保护等级；排产 Agent 在排程副本里模拟插单时，遵守保护等级约束，不强制推迟这类高保护等级订单的完工日期，先在普通订单之间找空间；要加班或外协，由车间主任拍板。

### 模拟出来的方案跟车间实际做出来差很远，怎么回事？

先查基础数据。排产方案的质量取决于标准工时、换型时间和物料到货日期准不准。如果车间实际换型耗时比系统登记的长，或者采购给的物料到货日频繁变动，算出来的方案代价就会失真。遇到从没生产过的产品组合，排产 Agent 缺少基础参数支撑，应该直接停下交由计划员和车间主任人工评估。

### 急单插单要动已经下发的任务，谁说了算？

已经下发到车间的生产任务默认处于锁定状态，急单插单优先在锁定范围以外的排程区间里找位置。如果确实需要调整已经下发锁定的任务，要由计划员在系统里明确执行解锁操作并写清楚解锁原因，再经过车间主任、计划、销售、采购会签批准后才能生效，排产 Agent 不能自行解锁已下发任务。
