询价表单可以按网页规范改造成方便 Agent 准确填写的结构，收到 Agent 询价后由销售做真假初判、拿不准的交销售主管拍板，自动提交进来的单子不直接发报价。网站负责人把规格、数量、交期、贸易条款和目的港拆成独立字段，加上「本次由 Agent 代填」勾选框以及委托人姓名、企业邮箱；销售先核邮箱域名与公司名是否一致、采购需求是否具体，再向委托人发确认邮件，拿到真人回复后才转入正式跟进。

## 采购端 Agent 填表常出什么问题

外贸卖方把产品页整理成方便机器读取的参数表之后，下一步就会碰到买家派工具直接来填表提交；落地页怎么给买方工具留可抽取的事实，见 <NoteLink slug="agent-buyer-b2b-landing-page">Agent 买家替企业比价时，B2B 落地页还按人来写吗？</NoteLink>。到了提交表单这一步，如果网页上只有一个笼统的留言框，或者输入框缺少清晰的标签名，代填工具就可能填错栏位，或者只留下一句泛泛的问价，漏掉规格、数量和目的港。

另一个问题是身份和权限分不清。企业间采购里，一个前来填表的 Agent 往往是通过某个人替某家企业办事，卖方得摸清两件事：它代表哪家企业，背后又是哪个人在指派。就算销售顺着公司名查到这家企业确实存在，也不能证明填表背后的这个人有权替这家企业对外询价办事；哪怕把人名和企业身份都核上了，身份确认也不等于采购授权。外来 Agent 在卖方网站上能干什么、提交后算不算有效询盘，决定权仍在卖方网站自己手里。

## 询价表单字段与标签怎么改

想让代填工具填得准、同时方便卖方筛查，市场或网站负责人要把网页标签和业务字段一并改规范。改前端结构时，表单采用规范的 HTML 标签编写，给每个输入框配上清楚的 label 标签，并写好 name 属性，并在表单旁边留出技术联系邮箱。自动填写属性直接采用 HTML 标准里的 autocomplete 字段名：公司名填 organization，邮箱填 email，电话填 tel；区分工作联系方式时可以在前面加 work，例如把企业工作邮箱写成 work email。

设计业务字段时，不要把所有采购条件全塞进一个大备注框，要把采购要素与委托人信息拆成单独字段。

- **采购要素字段**：把规格、数量、交期、贸易条款、目的港各自做成单独字段，让提交方把实单条件逐项填清。
- **代填勾选与委托人字段**：表单里专门加一个「本次由 Agent 代填」的勾选框，并配套设置委托人姓名、企业邮箱字段，把背后的指派人亮出来。

## 真假询盘怎么核与由谁拍板

表单改好后，后台收到的 Agent 询价不能见单就回盘，先核验再转跟进。销售先看表内信息能不能对上：检查委托人企业邮箱的域名，跟表单里填写的公司名称是否一致，同时看采购需求有没有具体到规格和数量。邮箱域名跟公司对不上，或者规格数量都没填的，先标成待核实，不进报价环节。

表内字段看着像实单的，再走真人邮件确认。工作流可以配置成向委托人企业邮箱发出一封确认邮件，请委托人本人回信确认这笔询盘。没拿到真人回复之前，自动提交进来的询盘一律不直接给报价。真假初判由销售负责；碰到情况复杂、拿不准真假的单子，转交销售主管定夺。

## 单独记来源与按成交结果回看

为了看清机器代填到底带来多少有效商机，市场和销售团队要在后台把来源记清楚。凡是勾选了代填标记的线索，在来源字段里单独记为「Agent 代填」，不跟普通网页留言混在一起，便于后面看这类 Agent 询价的成交情况；多渠道询盘进来后怎么记来源，见 <NoteLink slug="export-inquiry-whatsapp-email-attribution">询盘来源怎么记：AI 分拣 WhatsApp 询盘后</NoteLink>。

把「Agent 代填」单独记账后，销售主管和网站负责人定期拉出这批记录，顺着确认邮件回复情况、初判通过情况以及实际成交结果往回看。如果漏填目的港或贸易条款的单子大多没下文，就把对应字段调成必填；如果无企业邮箱域名的代填提交几乎没人回信，就在表单规则里收紧限制。是否允许自动提交、怎么防垃圾询价，都由卖方对照成交情况持续调整。

## 询价表单：常见问题

### 查到买方公司真实存在，就能直接给提交询盘的 Agent 发报价吗？

不能直接发报价。核实那家公司存在，证明不了操作工具的那个人有权代表公司对外询价，身份对上了也不等于拿到了企业授权。对自动提交进来的询盘，卖方要先向委托人企业邮箱发确认邮件，等拿到真人回复核实后，再由销售跟进报价。

### 表单里的 autocomplete 属性按什么名字写？

直接照 HTML 标准里的自动填写字段名写。公司名称用 organization，电子邮箱用 email，联系电话用 tel；如果要求对方填写工作联系方式，可以在字段名前面加 work，比如把企业邮箱标成 work email，配合清晰的 label 标签和 name 属性使用。

### Agent 询价要不要直接拦掉？

不必一刀切全部拦掉。卖方可以在询价表单里要求勾选代填标记并填清委托人姓名与企业邮箱，收到 Agent 询价后先核对邮箱域名和规格数量，再发确认邮件等真人回复。到底拦不拦、拦哪一类，由卖方网站自己定下明确规则，并定期对照实际成交情况调整。
