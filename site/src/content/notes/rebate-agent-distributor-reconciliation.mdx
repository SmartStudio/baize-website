渠道返利 Agent 算的数经销商不认，先别改数。让工具把这家经销商当期的返利底稿和对方提的差异逐项对上，标出差额出在哪处口径。属我方数据错的，财务改数并留调整记录；属条款理解不同的，渠道经理和经销商按合同核认，必要时补签说明；特批或口头承诺补审批件后再重算。最终返利对账单由商务和财务确认后外发，调完数的返利对账结果双方签认。

## 差异通常出在哪几处口径

季度或年度做返利对账，两边算的数对不上，多数是因为口径散在五个地方。不同部门各自按手头表格和习惯算，到结账节点就撞出差额：

- **条款版本**：年度合同、补充协议、特批、邮件承诺并存，双方算账依据的版本不一致。
- **销量口径**：按发货、签收还是回款算，基数含税还是未税，合同规定跟日常习惯没对齐。
- **退货冲减**：上期冲量达标的货本期整批退回，上期返利追不追回、冲减归哪一期，算法不同。
- **结算主体**：集团下有多家法人提货，销量算给签单主体还是收货主体，事先没理清。
- **兑付记录**：走冲抵下期货款、付现金还是给货，重复兑付和漏兑常藏在这里。

## 返利底稿要能复算到哪一步

每个经销商每个周期要做一张可复算的返利底稿，写明条款版本、计算基数、销量事实（发货单、退货单、回款流水）、退货冲减（退货日期、冲减归属期、重算前后档位）和兑付记录（方式、金额、凭证号、核销关系）。返利金额可以配置成由固定规则计算，渠道返利 Agent 负责解释差异、补齐证据、组织例外确认。

核对按固定顺序走：先锁定经销商、结算主体和周期；取当期有效条款版本和特批审批件；按条款口径取销量；退货按归属期冲减，跨期退货回溯重算上期档位；套条款算返利，记下公式版本和参与单据；跟已兑付记录比对，可以配置成拦截重复兑付和漏兑；逐项解释差异，口径冲突和特批进例外确认队列。每一步中间结果都留底：到了哪一档、差多少到下一档、哪些单据进了合计。经销商质疑时双方看同一张底稿，不用各自重新导表。

## 经销商提异议后怎么逐项对

经销商对返利对账结果提异议时，先核四样：条款版本、销量口径、退货冲减归属期、历史已兑付记录，多数异议都出在这四处口径不同。渠道返利 Agent 可以配置成把差异项放进例外确认队列，按规则分类处理：

- **跨期退货回溯**：上期拿货本期退回的跨期退货，按规则回溯重算上期档位，算出来的差额在底稿上单独挂账。
- **主体与口径对齐**：签单主体和收货主体不一致的，一律按合同主体归集；合同写回款而平时习惯按发货算的，先以合同为准，把差额列出来交给商务确认。
- **特批与聊天承诺核查**：业务员口头或聊天里的承诺只当待核实线索，正式计算要落到有版本的条款上；没有系统内条款的特批，补上审批件并经商务和财务双确认后才入库。

流程跑顺以后，团队可以盯着异议单数量、一次对平的比例这类数来评估运行效果，具体看哪些指标见 <NoteLink slug="agent-value-work-finished-metrics">Agent 上线后，效果评估该看哪几个数</NoteLink>。

## 改数、兑付和发对账单由谁批

确认返利金额、放行冲抵货款额度、对外发送对账单，这些动作都直接动钱，要由商务和财务按企业权限审批。Agent 整理的底稿和差异说明只作为审批依据，不能代替人工审批，也不允许把软件配置成自动多退少补直接过账。

兑付和冲抵货款跟日常付款一样都是资金关口，中间哪些审批与核销环节不能省，见 <NoteLink slug="ap-invoice-agent-payment-control">应付账款 Agent 从对账做到付款，中间哪几道关不能省</NoteLink>。发给经销商的沟通草稿可以由 Agent 先准备，经商务确认后再发出；查实是我方数据错的，由财务改数并留存调整记录；走冲抵货款的，同步建立核销关系防止重复支付，调完数的对账单经双方签认后归档。

## 渠道返利 Agent：常见问题

### 经销商集团下有多家法人拿货，销量算给谁？

按生效合同约定的主体归集。签单主体和实际收货主体不一致时，底稿以合同写明的结算主体为准汇总销量；要是确实需要把合同外关联法人的提货量并入计算，得先补签补充协议或走完审批件，由商务和财务确认后再入库。

### 上期冲量达标的货在本期退回来，返利怎么扣？

退货按归属期冲减。碰到跨期退货，按规则回溯重算上期档位，在底稿里记清退货日期、冲减归属期以及重算前后的档位变化，算出来的差额单独挂账：上期预估返利还没兑付的，直接按重算结果出结算单；上期已经冲抵了货款的，把差额转入下期核销，底稿后附上对应的发货单与退货单明细。

### 返利对账时经销商拿出业务员的聊天承诺，算不算？

不能直接拿来算账。返利对账时经销商拿出来的聊天承诺只当待核实线索；正式返利计算要落到有版本的合同条款，或者有审批依据的特批件上。没有系统内条款的特批，补齐审批件并经商务和财务双确认后，才入库参与重算。
