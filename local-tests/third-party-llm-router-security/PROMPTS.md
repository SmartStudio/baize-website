## Cover

Use case: stylized-concept. Asset type: 16:9 note cover. A single transparent orange API gateway cube at the center, with a narrow straight cable entering from the left and two clean, trusted destination nodes on the right. Outside the cube, a dark abstract, broken relay node is visibly disconnected behind a physical safety gap. The picture communicates removing an untrusted hop from an AI request path. No text. Full subject visible, generous margins.
